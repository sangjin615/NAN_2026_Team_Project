# 플레이테스트 — 이렇게 연다

**`greybox.html` 을 더블클릭한다.** 서버도 설치도 필요 없다.
(`fetch` 를 안 쓰고 스크립트 두 개만 읽는다 — `rules-v6.js` · `greybox.js`)

씨앗을 바꾸려면 주소 끝에 붙인다.

```
greybox.html?seed=777
```

**같은 씨앗이면 출품 96종·경쟁자·12일치 시세가 똑같다.** 판단만 바꿔서 비교할 수 있다.
끝나면 화면에 `새 판` · `같은 씨앗 다시` 가 뜬다.

---

## 12일 안에 20,000 을 100,000 으로 만든다

하루는 이렇다.

```
1  의뢰를 받는다      5종 중 3종이 제시되며 제시된 3건을 모두 받을 수 있다
2  정보를 산다        경쟁자 예산 · 출품 목록 · 수요 동향
3  경매 8점을 친다     감정 -> 응찰 또는 패스
4  판다              즉시 처분, 또는 족보로 묶어서
5  승급한다           보관칸이 늘고, 개시 마감을 넘긴다
6  다음 날
```

## 죽는 길이 둘이다

**개시 마감** — 정해진 날까지 상회 단계를 못 올리면 그 자리에서 끝난다.

```
4일차까지 2단계  ·  7일차까지 3단계  ·  10일차까지 4단계
```

화면 오른쪽 위 `개시 마감` 에 **다음 관문과 남은 날**이 늘 떠 있다. 이게 제일 자주 죽는 이유다.

**파산** — 자산이 0 이고, 팔 것도 없고, 대출도 못 받을 때.

## 알아둘 것

- **감정은 범위를 준다.** 확정값이 아니다. 1~3일은 ±35%, 4~6일 ±20%, 7~12일 ±10%
- **경쟁자는 품질을 안 본다.** 공개된 기준가와 시세로만 부른다 — 그래서 감정이 값을 갖는다
- **손익분기선도 추천 입찰가도 안 보여준다.** 일부러 그렇다(6.36). 숫자를 대신 계산해 주면 판단이 사라진다
- **낙찰한 물건은 다음 날부터 팔 수 있다.** 12일차 정산 때만 예외다
- **족보는 계약이 아니다.** 수락도 기한도 없다. 모아서 같이 팔면 배수가 붙는다
- **담보 대출은 2단계부터.** 처분가의 35% 를 빌리고 2일 뒤 x1.90 으로 갚는다. 조기상환은 원금만 갚고, 만기에 못 갚으면 담보를 뺏긴다

## 이 판이 얼마나 어려운가

시뮬 900판 기준이다. **사람이 이만큼 나오는지가 이번 플레이테스트로 보고 싶은 것이다.**

```
도달(100,000 이상)   54.7%
개시 마감 실패        32.1%
파산                 0%
생존자 중앙값         208,790
```

## 아직 없는 것

정직하게 적는다. **이건 그레이박스다 — 에셋이 없고 상자와 자리만 있다.**

- **이름과 그림이 없다.** 출품은 `에픽 · 장신구 · 기준가 12,000` 처럼 축으로만 나온다.
  나중에 API 가 이 축을 받아 이름을 만든다(`DATA-MAP.md` §5)
- **유물 경매(12일차 이후)가 없다.** 12일 경제까지만 돈다
- **출품 순서 채널이 없다.** 측정에서 값이 안 나와 보류다(`balance.json` 의 `informationRate.order: null`)
- **저장이 없다.** 한 판이 12일이라 앉은자리에서 끝난다
- **소리도 연출도 없다**

## 기록은 자동으로 쌓인다

오른쪽 아래 **플레이 기록** 상자에 `이 판 씨앗` · `누른 수` · `쌓인 판` 이 보인다.
브라우저에 남으므로 **새 판을 눌러도 앞 판이 안 사라진다.**

몇 판 하고 나서 **`기록 내려받기`** 를 누르면 `playtest-N판.json` 이 떨어진다. 그 파일만 주면 된다.

```
python -m http.server  같은 것 필요 없다. 그냥 눌러서 받으면 파일 하나다.
```

**담기는 것은 시드 · 누른 순서 · 시간뿐이다.** 화면 상태는 안 담는다 —
엔진이 시드에서 결정적이라 시드와 순서만으로 판 전체가 되살아난다. 되살아나는지는 검사가 확인한다.

시간은 수마다 둘로 담긴다.

```
t   여정 시작부터 걸린 시간
dt  앞 수와의 간격 — 여기서 멈칫한 시간이다
```

**탭을 벗어나 있던 시간은 뺀다.** 안 그러면 "고민 3분" 과 "커피 3분" 이 같아 보인다.
한 판마다 `elapsedMs`(실제 본 시간)와 `awayMs`(자리 비운 시간)도 따로 남는다.

```bash
node replay.js playtest-3판.json
```

```
씨앗    수    기록된 결말        다시 돌린 결말      자산              판정
555    28   개시 마감 실패      개시 마감 실패      19,000 / 19,000   O

PASS · 재현 안 되는 판 0
```

**어디서 오래 멈췄는지도 같이 나온다.**

```
행동          수      중앙 간격       제일 오래
appraise   1      8.2초        8.2초
pass       24     0.7초        1.1초

씨앗 555 · 한 판 0.5분
```

`비우기` 는 되돌릴 수 없다. 내려받고 나서 누르는 게 좋다.

## 이상하면 적어 주면 좋은 것

- 며칠차에 무엇 때문에 죽었나 (씨앗 번호와 같이)
- 어느 화면에서 **뭘 해야 할지 몰랐나**
- 어느 숫자가 **화면에 없어서 못 정했나**
- 반대로, 계산이 너무 뻔해서 **고민이 안 된 자리**
