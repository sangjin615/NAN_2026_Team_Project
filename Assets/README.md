# 원본 에셋 안내

이 폴더는 제작·편집용 원본 에셋을 역할별로 보관한다. 게임이 직접 읽는 배포용
파일은 `../Runtime/assets/`에 있으므로 두 위치의 역할을 혼동하지 않는다.

- `Scenes/` — 장소와 진행 단계별 전체 화면·배경 이미지
- `UI/Popups/` — 공통 팝업 UI 이미지
- `Items/` — 경매품 60종의 등급별 이미지와 카탈로그
- `Relics/` — 유물 이미지와 관련 데이터

## 관리 원칙

- 이 폴더는 원본 보관 위치이며 런타임 경로로 직접 사용하지 않는다.
- 게임에 반영할 때는 필요한 파일만 `Runtime/assets/`의 대응 위치로 복사한다.
- `Items/`의 `catalog.json`, `catalog.csv`, 각 `item.json` 경로를 함께 관리한다.
- 폴더를 다시 옮기기 전에는 문서와 도구의 경로 참조를 검색한다.
