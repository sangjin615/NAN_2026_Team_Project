# 미지의 경매장 V6 — 사운드 바이블

기준 문서: V6 통합기획서 · 구현 계약 패키지 v6.3
수치 소유: `sound.json` — 이 문서는 값을 적지 않는다. 값이 어긋나면 언제나 `sound.json`이 옳다.

---

## 1. 한 문장

**햇빛 드는 유럽 항구의 따뜻한 상업 모험.** 효과음은 양피지·짙은 목재·광택 있는 황동·유리·펠트의 픽셀 스토리북 물성을, 음악은 장면별 챔버 포크와 절제된 살롱 음악을 맡는다.

### BGM의 세 축

- **항구 상업 실내악:** 타이틀·도시·상회·결산·결과. 피치카토 현악, 클라리넷/바순, 스피넷과 작은 프레임 드럼.
- **경매 누아르:** 일반 경매 3곡만 재즈를 유지한다. 콘트라베이스, 브러시, 드문 저음 목관 킥. 음악 밀도는 핑크팬더풍보다 훨씬 낮다.
- **유물의 기억:** 유물 경매·판정·실패·전시관. 비올 다 감바, 포지티브 오르간, 유리 하모닉. 유물은 경제 밖의 영구 성장이므로 웅장한 전투곡이 아니라 조용한 의식으로 다룬다.

**폐기한 방향:** 영웅적 상인 모험곡, 관광지풍 항구 음악, 과도한 스팀펑크 공장 리듬, 유물 경매의 블록버스터 웅장함, 술집 재즈.

## 2. 세 층의 톤

기획서 §3.3의 층별 핵심 감정에 사운드를 대응시킨다.

| 층 | 느껴야 할 것 (§3.3) | 사운드가 맡는 것 |
|---|---|---|
| 개별 출품 | 싸게 살 수 있을까? 지금 놓아야 하나? | 입찰·망치의 물리적 무게 |
| 한 세션 | 내 윈플랜이 통하는가 | BGM-03/15/16 재즈 레이어가 공개 호가와 함께 쌓임 |
| 하루 운영 | 돈을 어디에 쓸까 | 동전 큐가 모든 지출에 겹쳐 붙음 |
| 족보 조립 | 지금 팔까, 짝이 올 때까지 들고 있을까 | **`sfx-hanbo-complete`** — 최대 보상 |
| 마감 압박 | 3일 안에 승급 못 하면 끝난다 | 태엽 시스템 (§4) |
| 유물 경매 | 12일이 이 호가 하나로 채점된다 | BGM-04 3레이어가 음량보다 음역·공명으로 확장 |

## 3. 재질 팔레트

**쓰는 것** — 황동 · 태엽·톱니 · 목재 · 유리 · 종이·양피지 · 밀랍 · 먼지

모든 효과음은 이 일곱 가지 중 하나 이상으로 설명될 수 있어야 한다. 설명이 안 되면 그 소리는 이 게임 것이 아니다.

**녹음 질감**

- 스테레오는 좁게. 화면 안의 물건에서 나는 소리다.
- 아날로그 테이프 새추레이션 약하게.
- 12kHz 이상 완만히 감쇠 — 디지털적인 반짝임을 만들지 않는다.
- 60Hz 이하 컷. 서브베이스는 유물 경매에만 허용.

**금지**

- 디지털 비프·신스 블립
- 리버스 신스 스윕
- 현대적 UI 클릭 (맥/윈도우 시스템음 계열)
- 광대역 홀 리버브 — 일반 씬은 실내 짧은 잔향만
- 코믹한 만화 효과음
- **음정이 뚜렷한 멜로디를 가진 효과음** — 예외 3종만: 족보 성립 · 상회 승급 · 유물 획득

마지막 항목이 이 게임의 톤을 지킨다. 소리에 멜로디가 붙는 순간이 곧 "여기가 보상이다"라는 신호이므로, 아무 데나 붙이면 그 신호가 죽는다.

## 4. 태엽 시스템 — 장식이 아니라 구조

12일이라는 여정 길이를 소리가 함께 진다.

| 시점 | 큐 | 내용 |
|---|---|---|
| 타이틀 로고 등장 | `sfx-title-logo` | 큰 태엽 3회 감김 — 여정이 감긴다 |
| 날짜 전환마다 | `sfx-day-advance` | 태엽 한 칸 감김 — 12일의 기본 박자 |
| 마감 일차 직전 | `amb-deadline-tick` | 초침 레이어를 −24dB로 아주 얕게 |
| 파산 | `sfx-result-bankruptcy` | **태엽이 풀리다 멈춤** — 모티프의 종착점 |
| 완전한 결말 | `sfx-campaign-complete` | 여러 태엽이 동시에 맞물려 돌기 시작 |

### 불변 9 준수 근거

기획서 불변 9는 손익분기선·안전 입찰가·추천 입찰가를 화면에 표시하지 않는다고 못박았다. 소리도 같은 제약을 받는다.

`amb-deadline-tick`이 이 선을 넘지 않는 이유:

1. **새 정보를 주지 않는다.** 일차는 이미 상단바에, 마감 잔여 경고는 이미 `scene-summary`의 「마감 잔여 경고」 핀에 표시되어 있다. 초침은 이미 보이는 사실의 정서적 보강일 뿐이다.
2. **판단을 대신하지 않는다.** 얼마를 벌어야 하는지, 무엇을 사야 하는지 알려주지 않는다.
3. **§6.2가 마감 실패 33.2%를 이 게임의 주된 실패 원인으로 규정**했다. 주된 실패 원인이 무음인 것이 오히려 설계 누락이다.

**같은 이유로 금지되는 것:**

- 좋은 물건·나쁜 물건의 입찰음을 다르게 하지 않는다 (불변 6 — 봇이 품질을 모르는데 플레이어 귀가 알면 안 된다)
- `sfx-appraise-reveal`은 감정 결과의 좋고 나쁨과 무관하게 **항상 동일**하다
- 손익분기선을 넘는 호가에 경고음을 넣지 않는다

## 5. 믹스

### 버스

```
master
├─ bgm  (0.65)
│   └─ ambience (0.35, bgm에 종속)
└─ sfx  (0.85)
```

`modal-settings`의 마스터/BGM/SFX 음량 슬라이더 3개에 그대로 물린다. 앰비언스는 별도 슬라이더를 두지 않고 BGM에 종속시킨다 — 설정 항목이 늘어나는 것보다 낫다.

### 덕킹

| 트리거 | 감쇠 | 유지 |
|---|---|---|
| `sfx-gavel` | −6dB | 0.6s |
| `sfx-hanbo-complete` | −4dB | 0.8s |
| `sfx-relic-gavel` | −9dB | 1.2s |
| `sfx-result-bankruptcy` | −12dB | 2.0s |

### 음량 기준

- BGM: −20 LUFS integrated
- 일반 SFX: −18 LUFS short-term
- 강조 SFX: −14 LUFS short-term (망치 · 족보 · 유물 · 파산)
- True Peak 상한: −1.0 dBTP

### 동시발음

기본 3. `sfx-ui-hover` 1 / `sfx-ledger-line` 8 / `sfx-bid-bot` 2.
재트리거 가드 기본 40ms, 호버 120ms, 클릭 60ms.

## 6. BGM 전환 규칙

- **같은 곡, 다른 씬** → 재시작하지 않는다. 재생 위치를 유지한 채 씬만 바뀐다. 거점 6곳을 오가는 동안 곡이 계속 이어져야 한다.
- **다른 곡** → 1.8초 equal-power 크로스페이드
- **실패로 인한 결과 씬 진입** → 0.6초. 실패는 급격히 끊는다.
- **레이어 드나듦** → 곡을 재시작하지 않고 같은 재생 위치에서 페이드 인/아웃만

## 7. 파일 규약

```
assets/runtime/audio/
├─ bgm/
│   ├─ bgm-01-title__intro.ogg
│   ├─ bgm-01-title__loop.ogg
│   ├─ bgm-03-auction__L1.ogg
│   ├─ bgm-03-auction__L2.ogg
│   └─ ...
├─ sfx/
│   └─ sfx-gavel.wav
└─ ambience/
    └─ amb-auction-crowd.ogg
```

| 종류 | 포맷 | 비고 |
|---|---|---|
| BGM | ogg vorbis q6 (~192kbps) / 44.1kHz / 스테레오 | 레이어는 `__L1` 접미사 |
| SFX | wav 16bit / 44.1kHz / **모노** | 공간감은 재생 시 팬으로 |
| 앰비언스 | ogg vorbis q4 / 44.1kHz / 스테레오 | 루프 이음매 필수 |

예상 파일 수: BGM 33 + SFX 99 + 앰비언스 11 = **143개**

## 8. V6 정합성

### 큐를 만들지 않는 것 (폐기·보류)

| 행동 | 근거 |
|---|---|
| `act-accept-set-contract` / `act-fulfill-set-contract` | §19 #20 — 세트 계약형 폐기, 족보형으로 대체 |
| `act-close-contract-result` | 위와 연동 |
| `act-buy-relic-clue` | §19 #17 — 유물 경매가 경제 밖이라 팔 것이 없다 |
| `act-buy-lot-order` | §10.1 — 출품 순서 채널 `null` 보류 |

flow.json v6.3에는 아직 이 행동들이 남아 있다. **여기에 효과음을 붙이면 폐기된 기능에 예산을 쓰는 것이므로 만들지 않는다.**

### 행동이 없어서 큐만 정의해 둔 것

| 제안 ID | 큐 | 근거 |
|---|---|---|
| `act-buy-lot-catalog` | `sfx-info-buy` | §2.1 출품 목록 채널 부활 — V6 정보 채널 4종 중 유일하게 flow.json에 행동이 없다 |
| `act-form-hanbo` | `sfx-hanbo-complete` | §11.2·§11.4 — **핵심 판단의 보상 순간을 잡는 행동이 없다** |
| `act-reveal-appraisal` | `sfx-appraise-reveal` | `popup-appraisal-result`가 spec-only |

`act-form-hanbo`가 특히 중요하다. §11.4가 "지금 팔까, 짝이 올 때까지 들고 있을까"를 이 게임의 핵심 판단으로 규정했는데, 그 판단이 보상받는 순간을 잡는 행동이 계약에 없다. 사운드 이전에 기능 명세의 구멍이다.

### 채널 명칭

flow.json v6.3의 정보 채널명이 V5 기준이다. 화면 문구를 V6로 갱신해도 **큐는 그대로 유지된다.**

| flow.json 행동 | V5 표기 | V6 채널 (§10.1) |
|---|---|---|
| `act-buy-market-forecast` | 시장 예보 | 수요 동향 (0.4%) |
| `act-buy-competitor-info` | 경쟁자 정보 | 경쟁자 예산 (0.8%) |

## 9. 검수 체크리스트

납품된 소리를 받았을 때 이 순서로 확인한다.

1. **재질 테스트** — §3의 일곱 재질 중 하나로 설명되는가
2. **멜로디 테스트** — 예외 3종이 아닌데 음정이 들리는가 → 반려
3. **누설 테스트** — 결과의 좋고 나쁨을 소리가 미리 알려주는가 → 반려 (불변 6·9)
4. **반복 테스트** — 도시 BGM을 10분 연속 들었을 때 거슬리는가
5. **루프 테스트** — 이음매에서 클릭·톤 점프가 들리는가
6. **레이어 테스트** — L1만 / L1+L2 / L1+L2+L3 각각이 완결된 곡으로 들리는가
7. **음량 테스트** — 강조 SFX가 BGM을 덮는가, 일반 SFX가 묻히는가
