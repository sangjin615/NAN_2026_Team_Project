# SFX 전면 재정립 v3.3

기준은 사용자가 통과시킨 BGM 7곡과 `selectedBgmProgram 3.2`다. 이번 버전은 99개 SFX와 11개 앰비언스, 총 110개 파일을 모두 다시 렌더링했다. BGM 33개 런타임 마스터의 바이트는 v3.2와 동일하게 보존했다.

## 한 문장 원칙

SFX는 손에 닿는 재질과 기능만 말하고, 멜로디·감정·진행감은 BGM에 맡긴다.

## 감사 결과와 수정

| 문제 | 기존 경향 | v3.3 조치 |
|---|---|---|
| 현대적인 UI 인상 | 980~1180Hz 황동 핀과 유리 핑이 반복 | 펠트 래치, 낮은 목재 버튼, 눌린 황동 접점으로 교체 |
| 과도한 음악성 | 타이틀·이동·시장·결산·결과에 벨과 상행 음형 사용 | 일반 큐의 벨과 음형 제거. 보상 멜로디는 3개 큐로 제한 |
| 경매 재즈와 충돌 | 입찰마다 고역 황동 핀이 반복 | 플레이어는 마른 목재 패들, 봇은 종이 카드와 낮은 목재 접점으로 분리 |
| 거점의 정서 과장 | 의뢰소 유리 핑, 상회 준비 벨, 거래소 밝은 금속음 | 종이·렌즈 걸쇠·장부 기어·펠트 기계음 중심으로 재구성 |
| 의식음의 과장 | 유물/결과 스팅의 긴 잔향, 합창, 3음 벨 | 짧은 벨벳 공간감, 목재 봉인, 2음 이하의 눌린 봉인 종으로 축소 |
| 앰비언스 과밀 | 기어·종이·의자 이벤트가 짧은 간격으로 반복 | 사건 밀도를 약 30~50% 감소하고 방의 위치감만 남김 |
| 런타임 믹스 미구현 | `sound.json`에는 덕킹이 있으나 재생기에 반영되지 않음 | 4개 핵심 큐에 실제 -3~-7dB BGM 덕킹 구현 |

## 장면별 팔레트

| 장면군 | 주재료 | 피한 요소 |
|---|---|---|
| 타이틀·도시 | 장부 표지, 목재 걸쇠, 종이, 작은 펠트 기어 | 영웅적 상승음, 서비스 벨, 밝은 UI 핑 |
| 의뢰소·거래소·조합·상회 | 연필, 렌즈 걸쇠, 주판, 금고 레버, 작업 기어 | 유리 마법음, 카지노 코인음, 공장식 금속 반복 |
| 술집 | 가죽/천, 정보 카드, 낮은 토큰 접촉 | 포크 악기처럼 들리는 플럭, 밝은 동전 멜로디 |
| 일반 경매 | 목재 패들, 입찰 카드, 장부, 마른 망치 | 황동 핀, 음정형 승패 알림, 재즈 중역을 가리는 잔향 |
| 유물 경매 | 벨벳, 낮은 목재 전시대, 봉인 황동, 무거운 망치 | 합창, 판타지 스파클, 긴 홀 리버브 |
| 결산·결과 | 종이, 연필, 주판, 장부 봉인 | 축하 벨, 패배 하강음, 감정을 선판정하는 스팅 |

## 멜로디 허용 큐

- `sfx-hanbo-complete`: 눌린 황동 2음
- `sfx-upgrade`: 기어 체결 뒤 눌린 황동 2음
- `sfx-relic-acquire`: 낮은 봉인 종 2음

그 외 큐는 높낮이가 있더라도 악기 프레이즈가 아니라 물체의 공진으로만 들려야 한다.

## 레벨과 기술 결과

- 110/110 파일 존재, 계약 길이 오차 2ms 이하
- SFX mono, 앰비언스 stereo, 전부 44.1kHz PCM WAV
- 기본 볼륨에서 가장 큰 계산 피크: -13.14dBFS
- 6kHz 이상 에너지 비율 최댓값: 0.01593
- 과했던 의식/결과 큐 메타 게인: 2~6dB 하향
- 로딩 기어 앰비언스: -18dB에서 -24dB로 하향
- 상세 측정값: `SFX-MIX-AUDIT-v3.3.json`

## 수정 파이프라인

```powershell
python tools/generate_prototype_audio.py --sfx-only --force
python tools/audit_sfx_mix.py
python tools/sync_vsl_sound_editor.py
python tools/package_release.py
python tools/verify_release_zip.py
```

`--sfx-only`는 승인된 BGM 마스터를 절대 덮어쓰지 않는다. 향후 3~10개 큐 단위 수정 시에는 `--cue sfx-id`를 반복해 선택 렌더링할 수 있다.
