# 설계 결정 — 수동 세트 태그

- 상태: 결정 (프로토타입 반영 완료)
- 기준 명세: `../00-product-spec.md` §7.7 (자동 세트 태그 제외 조항)
- 선택한 안: 플레이어가 물건마다 세트 1·2·3 추측 태그를 수동으로 붙인다. 클릭 순환(없음→1→2→3→없음), 태그명은 해당 판의 공개 세트 이름, 세트별 색상 구분. 필터 지원. 카탈로그·경매 준비·보유 목록에서 편집.
- 잠금 규칙: 메모·관심 표시와 달리 **경매 종료 후에도 게임 끝까지 수정 가능**. 최종 결과에서만 읽기 전용이며 실제 세트와의 일치 여부를 단순 표시한다(자동 해설 아님).
- 선택 이유: §7.7의 취지는 자동 분류·정답 힌트 금지이며 수동 계획 도구는 이를 침해하지 않음. 소유자 전용 설명을 본 뒤 추측을 갱신하는 흐름이 복기 재미를 강화.
- 결정자: 최재혁
- 결정일: 2026-07-19
- 반영 위치: `prototypes/claude-mvp/` (ui.js·style.css·body.html), 기획서 v1.2 변경 이력
- 재검토 조건: 플레이테스트에서 태그가 정답표처럼 오용되거나 UI 과밀이 관찰될 때
- 후속: 공식 구현(public/auction/) 이식은 A07(빠른 판단 표시)과 통합 여부를 보드에서 결정
