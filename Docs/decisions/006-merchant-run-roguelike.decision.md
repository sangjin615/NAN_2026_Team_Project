# 설계 결정 — 상회 육성 로그라이크로 중심 재정의

- 상태: 방향 합의 (상세 설계·플레이테스트 미착수)
- 배경: 프로토타입 반복 검토에서 경매 규칙보다 근본적인 문제 확인 — "플레이어가 왜 돈·평판을 모으고 왜 다음 경매에 참가하는가"가 없음. 패스 도입 시 순수 경매 플레이 약 7분으로, 입찰만으로는 한 런의 중심 경험을 만들기 어려움.

## 선택한 안

**정해진 기간 동안 경매와 거래로 상회를 성장시키고, 마지막 초고가 경매에서 고정 템플릿 영구 유물을 노리는 상회 육성 로그라이크.**

핵심 가설: *매 런 달라지는 물건으로 돈을 벌고 상회를 키우되, 마지막에는 그 부를 고정된 전설 유물로 바꿔 영구적인 성취를 남긴다.*

### 런 구조

AI가 도시·NPC·물건·시장 사건 생성 → 제한 기간 동안 경매(매입)·감정·판매·의뢰 → 돈·인맥·시설·전문성으로 상회 성장 → **상회 엔딩을 최종 경매 전에 확정** → 성장 단계에 맞는 초고가 특별 경매 → 영구 유물 낙찰 시도 → 유물·도전과제 계정 영구 기록.

### 층별 목적

| 층 | 플레이어가 느껴야 할 것 |
|---|---|
| 개별 경매 | 싸게 살 수 있을까? |
| 판매·의뢰 | 어디에 팔아 가장 많이 벌까? |
| 하루 운영 | 돈을 정보·시설·매입 중 어디에 쓸까? |
| 상회 성장 | 거래 규모가 커지고 있다 |
| 최종 경매 | 모은 부를 어디까지 쏟을 것인가? |
| 영구 전시관 | 이번 런의 성취가 남았다 |
| 도전과제 | 다음에는 다른 방식으로 운영해보자 |

### 핵심 설계 규칙

1. **상회 엔딩 판정과 최종 유물 소비의 분리**: 상회 평가를 먼저 확정한 뒤 남은 현금으로 최종 경매. 분리하지 않으면 유물 구매가 상회 평가를 깎아 "유물을 안 사는 게 유리"해지는 역설 발생.
2. **의뢰는 중심 목표가 아니라 돈벌이 수단 중 하나**: 의뢰가 중심이면 키워드 매칭 체크리스트 게임으로 축소. 숨은 태그 누설·후보 자동 평가 금지.
3. **물건 2층 분리**: 런 안의 거래품(AI 생성, 런 종료 시 초기화) / 영구 소장 유물(고정 템플릿, 전시관 영구 보존, 콘텐츠 해금). 모든 물건 영구 보존은 판매 의미를 죽이므로 유물만 영구.
4. **영구 유물은 고정 템플릿 풀**: 완전 생성형이면 비교·도감·공유 목표·희귀도 체감이 불가. AI는 유물의 "이번 판 출품 사정"(소유자·경위·경쟁자 목적·소문)만 생성.
5. **거래 단위의 단계 상승**: 초반 수천 G → 중반 수만~수십만 G → 후반 컬렉션 일괄 수십만~백만 G → 최종 유물 수백만 G. 절대 금액이 아니라 자릿수 변화가 성장감. 가격과 함께 물건의 격·구매자 지위·거래 방식·위험도 함께 상승.
6. **턴당 자동 수입은 파산 방지 보조 장치로만**: 자동 수입은 "판단으로 돈을 벌었다"는 감각을 못 만들고 유지비와 상쇄될 뿐.
7. **AI/엔진 역할 분리 유지**: 고정 엔진 = 성장 수치·사건 조건·선택 효과·엔딩 판정·가격·경매 규칙 / AI 생성 = 도시 분위기·NPC·물건 설명·사건 맥락·대사·경쟁자 동기. (스펙 §2.2 "생성=표현, 알고리즘=판정" 원칙의 확장 적용)
8. **도전과제 보상은 경제 능력치 금지**: AI 생성판은 최고 금액만으로 공정 비교 불가하므로 조건형 도전과제(경제·운영·경매·수집)로 보완. 보상은 유물·도시·구매자·사건·외형·역할·특수 경매 방식 등 콘텐츠 해금만.

## 판단 경위 (요약)

1. 세트 수집 경매: 세트 관계는 쉽게 읽히고 가치 추론은 어려움, 세트 올인 우세, 잔액 무의미, 판 종료 후 성취 부재 → 외부 목적 필요.
2. 의뢰 시스템: 방향은 주지만 중심이 되면 체크리스트화, 돈 번 감각 여전히 약함 → 의뢰 격하.
3. 짧은 캠페인 + 최종 유물 단일 목표: 현금 비축 우세 전략으로 중간 경제 활동 위축 → 상회 성장과 유물 획득 분리.
4. 지도형 거점 + 판매 시장: 낙찰→감정→구매자 비교→판매/보관 흐름으로 개선. 그래도 "돈 벌었다"보다 "비용을 감당했다"에 가까움.
5. 턴당 수입 검토: 핵심 문제 해결 못 함 → 보조 장치로 격하.
6. 중심 재정의: "저평가 물건을 사서 적합한 구매자에게 팔아 상회를 키운다."

## 기존 결정과의 관계

- **003(3판 연전 + 증강 드래프트) 대체**: 메타루프 뼈대가 런 구조 자체로 확장됨. 003의 "도감/수집형 메타 기각"은 부분 번복 — 기각 사유(팩 2종 소진)는 고정 템플릿 유물 풀 + 도전과제 해금 구조로 전제가 바뀜.
- **004(봇 성향 트리) 유지**: 경매 층의 봇 설계로 계속 유효. 경쟁자에 "동기"(AI 생성) 층 추가 여지.
- **스펙 00 불변 조건과 충돌**: "최초 경매 물건 12개·단판 구조·잔액 점수 미포함(§14)"은 런 구조·돈 중심 경제와 상충. 스펙 전면 개정 또는 신규 스펙 문서(01-run-spec) 필요 — 별도 태스크.
- **확장성 우선 합의(2026-07-20 브레인스토밍)**: 개연성과 확장성은 트레이드오프. 당장은 파인 튜닝보다 확장성, 스토리보다 메인 게임플레이.
