# 설계 결정 — 메타루프 방향

- 상태: 방향 합의 (상세 설계 미착수)
- 배경: 플레이테스트 결과 총 경과 약 5분, 실제 플레이 약 2.5분. 메인 루프(한 판)의 콘텐츠·밀도는 유지하고, 부족한 것은 판 바깥의 메타루프로 진단.
- 선택한 안: **3판 연전 런 + 판 사이 경제형 증강 드래프트(3택1)** 를 메타루프 뼈대로 한다. 증강은 알고리즘 계층의 수정자(보너스·인상폭·환불·자금 등)로 한정하고, 이름·플레이버는 해당 판 세계관으로 표현한다(생성=표현, 알고리즘=판정 원칙 유지). 스펙의 15분 목표는 "한 판"이 아니라 "한 세션" 목표로 재해석한다.
- 보류·기각한 대안: 도감/수집형 메타(생성형 콘텐츠 컨셉과 상충, 팩 2종으로는 소진 빠름 — 기각), 도전과제(깊이는 더하나 길이를 보장하지 않음 — 후순위), 봇 연출 지연 증가(나쁜 시간 — 기각), 물건 수 확대(명세 불변 조건 — 결정 문서 없이 불가).
- 경계 조건: 정보형 증강(타인 정보 열람류)은 추론 공정성 훼손 위험 — 1차 범위에서 제외. 봇 증강은 도입 시 공개형(읽을 수 있는 압력)으로.
