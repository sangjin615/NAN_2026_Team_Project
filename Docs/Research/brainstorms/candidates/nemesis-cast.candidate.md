# 후보 — 숙적 상시화 캐스트 (숙적 1 + 전원 뜨내기)

- 상태: 작성됨 (2026-07-24, 최재혁 × Claude 대화 세션) — 검토 대기
- 중심 축: 캐스트 구조 (§6 개정 후보) — "단골 2+뜨내기 1"을 "숙적 1(상시) + 뜨내기 2(전원 교체)"로

## 한 문장 정의

세션 간 연속성을 단골 여럿에 분산하지 않고 숙적 하나에 몰빵하며, 나머지 좌석은 매 세션 새 얼굴(각자 욕망 보유)로 채운다.

## 핵심 루프

세션 시작: 주점 브리핑(경량 L3)으로 오늘의 뜨내기 부분 정보 구매 가능 → 경매: 숙적(런 아크) + 뜨내기(세션 미니 아크)와 경합 → 세션 간: 숙적 프로파일 갱신·성장 단계 예고 관찰.

## 반복되는 플레이어 판단

"숙적의 다음 수는?" (깊은 읽기, 런 스케일) / "저 낯선 자의 욕망은 뭔가?" (빠른 읽기, 세션 스케일) / "정보를 살 것인가 관찰로 벌 것인가" (골드 vs 안목).

## 전체 카탈로그의 역할

변경 없음. 단, 뜨내기 지정형 사정 대상이 그 세션 카탈로그에서 추첨되므로 "이 물건에 누가 붙을까"의 답이 매 세션 갱신됨.

## 경쟁자의 역할

- **숙적 (상시, 2세션차부터)**: 런 관통 사정 아크 보유. 성장 = 사전 정의 파라미터 스케줄(노이즈 ±30→±15, 정보 폭 확대, Tier2 리드 식별 개시)을 세션 진행/아크 국면에 따라 계단 해금, **각 단계는 소문으로 공표**(고무줄 아닌 서사 — 노이즈 예외의 "공표하면 해소" 논리 재사용). 소모전·지갑 추적의 유일 대상.
- **뜨내기 2 (전원 교체)**: 조건형 + **지정형 사정 허용** — 세션 내 미니 아크(등장→무리→충족 퇴장). 세션 지갑. 1회성이지만 욕망이 있어 "사람"으로 지각.
- 1세션차: 숙적 부재, 약한 뜨내기 구성 (튜토리얼 접대).

## 정보 공개 구조

- 주점 경량판(세션 브리핑): 뜨내기 **부분 정보만** 판매 — 뿌리 힌트 수준, 사정 절대액 비매품 (읽기가 쇼핑이 되는 것 방지).
- 상회 런중 강화에 정보력 강화 트랙 편입 (브리핑 정밀도 상승 등).
- 정보 대칭 원칙 유지: 술집은 유저 독점 우위 방향이라 무충돌.

## 현재 명세에서 변경하는 가설

- §6.1 캐스트 2층(단골 2+뜨내기 1) → 본 구조로 대체.
- "3~4판 뿌리 구분"(단골 프로파일링) 가설 폐기 → "숙적 1인 깊은 읽기 + 뜨내기 세션 내 읽기 + 구매 정보"로 대체.
- 숙적 등장 조건(상회 단계 2) → 2세션차 고정 + 성장 스케줄로 대체.
- 사정 아크: 런 스케일(숙적 전용) + 세션 스케일(뜨내기 미니 아크)로 재배치.
- L3 소문 훅: "자리 예약" → 경량 구현으로 승격 (MVP 범위 재판정 필요).

## 장점

① 단골 황혼 문제 소멸 (열린 질문 1순위 해소) ② 지갑 비연동 표현 균열 축소 (뜨내기=세션 지갑, 추적 대상은 숙적뿐) ③ 단골 관리 구현량 증발 (재충전·교체 서사·비율 튜닝) ④ 서사 집중 — "당신을 기억하고 성장하는 숙적"은 상황 반응 대사와 결합 시 AI 가시성 최대 지점 ⑤ 미검 가설(뿌리 구분)을 팔아 확정 문제를 갚는 거래.

## 가장 강한 반론

세션 간 축적 관찰(유저 최대 정보원)의 대상이 1인으로 줄어 안목 게임의 학습층이 얇아진다. 매 경매가 첫 만남 = 역선택 공포 상시화 — 정보 모델이 스스로 물었던 "스릴인가 스트레스인가"가 전면화. 주점 구매 정보가 관찰 재미를 대체하면 정체성 훼손.

## 예상 실패 양상

① 뜨내기 읽기가 세션 내에서 안 되면 → 유저가 읽기를 포기하고 무지성 예산 관리 게임화 ② 숙적 성장 스케줄 후반이 벽 → 클리어율 급락 ③ 주점 정보가 너무 싸거나 정확 → 관찰 무의미 ④ 뜨내기 사정 밀도 부족 → 누설 잔차 상승 (군중 지혜 부활).

## 구현 복잡도

순감소 추정: 단골 관리 삭제 > (주점 경량판 + 성장 스케줄 + 뜨내기 지정형) 추가. 성장 스케줄은 파라미터 표 하나 (러닝 아님 — plan=정책 고정·시드 재현 유지).

## 자동 검증 방법

sim.py에 `cast_mode` A/B (현행 vs 본 후보, 동일 시드 720판): ① 무경합 낙찰 비율 (최소 경합 보장선 유지) ② 유저 대리 봇 ROI 분산 변화 (읽기 불가 리스크) ③ 누설 잔차 ≤0.3 유지 (뜨내기 사정 밀도 스윕 병행) ④ 숙적 성장 단계별 유저 대리 봇 승률 곡선 (후반 절벽 검출). E02 하네스에 성장 스케줄 재현성 회귀 추가.

## 최소 플레이테스트

### 관찰할 행동

세션 2~3에서 뜨내기 행동을 보고 언어화하는가 ("쟤는 도자기에 미쳤네") / 주점 브리핑을 사는가, 산 정보를 입찰에 쓰는가 / 숙적 성장 예고(소문)에 반응이 있는가 / 무경합 낙찰 직후 표정·발화 (역선택 공포 체감).

### 성공 기준

뜨내기 욕망을 세션 내 2회 관찰로 언어화 성공 / 숙적 이야기를 플레이어가 먼저 꺼냄 / "누가 나올지 모른다"를 스릴로 서술.

### 실패 기준

뜨내기를 "그냥 방해물"로 서술 / 주점 정보 무시 또는 정보만으로 플레이 / 숙적 성장을 불공정("갑자기 세졌다")으로 서술 → 공표 장치 실패.
