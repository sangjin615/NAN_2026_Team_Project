## 추천안

**안 3 — 전매 뿌리 신설 (뿌리 4 × 브랜치 3, 좌석은 "서로 다른 뿌리 3개")**

004의 트리 철학("뿌리 = 행동에 가장 크게 드러나는 축, 브랜치 = 확신 못 하는 변주")을 보존한 채 V2의 새 행동 축(전매)을 흡수하는 유일한 안이다. 안1은 설계 과제 2와 "런 종료 자금 소진" 가설을 정의조차 못 하고, 안2는 004가 자유 조합을 기각한 이유(뿌리 읽기 노이즈화)를 재도입한다.

### 추천 근거 (검증 가설 대조)

1. **"가치 불문 매수" 억제**: 뿌리 D가 저평가 물건을 공정가 근처까지 받아침 + A·B·C의 동기 태그 물건 과열. 무지성 매수는 "공정가+수수료"를 내게 되어 판매층에서 마진이 안 남는다.
2. **런 종료 자금 소진**: 수집형(A·B·C)은 환금이 없어 지갑이 실제로 준다. 전매형(D)은 회전하지만 그것이 곧 "런 내내 지속되는 압력"이라는 역할 정의다. "소진"의 측정 대상을 수집형으로 명시.
3. **3~4판 뿌리 구분**: 런 캐스트가 지속되므로 같은 경쟁자를 반복 관찰 가능. 뿌리별 행동 시그니처(§5 매핑 표의 '판별 단서' 열) 참조.
4. **E02 테스트 가능성**: 전 파라미터를 단계 상대 앵커 `A_s` 배수의 무차원 값으로 정의 (§6 파라미터 표).

## 설계 과제 답변

### 1. 004 승계 판정

comparison §0.3의 표가 정본. 요약: 유효 7 (A1·B2·C2·C3·점프 파라미터화·interest 분리·노이즈 ±30%), 수정 7 (A2·A3·B1·B3·C1·타인 보유 읽기·시드 선택 규칙), 폐기 2 (소진 압력 공식 원형·메타루프 연계), 근거 교체 1 (상한 캡 — 캡은 유지, §14.3 동률 근거만 폐기).

### 2. 전매 동기 축 — 뿌리 D 산식

```
계열온도 T_c   = clamp(0.8, 직전 k건 중 해당 계열 (낙찰가/est_bot) 평균 × 시장사건 보정, 1.3)
기대전매가 R   = est_bot × T_c × 환금배수(브랜치별)
maxPay        = R × (1 − 목표마진) − 거래비용(수수료율 × R)
캡            = min(maxPay, est_bot × 1.5)
```

- 모든 입력이 봇 자신의 노이즈 추정(est_bot)과 공개 시장 신호뿐 — 실제 가치·숨은 태그 비참조 (불변 제약 5).
- plan 시점에 전부 계산·고정 (불변 제약 3). 계열온도의 "직전 k건"은 이전 세션까지의 이력이므로 plan 입력으로 합법.
- 브랜치: D1 마진 고정형(0.20) / D2 회전율형(0.10, 광범위 interest, 환금 1일) / D3 매점형(단일 계열 0±0.05, 일괄 프리미엄 환금 ×1.3, 지연 3일+). 상세는 comparison 안3.
- 압력 효과: 현재가가 est_bot×(1−마진) 아래인 동안 D는 따라온다 → 플레이어의 저평가 차익은 "노이즈 ±30%로 D의 추정이 빗나간 물건"과 "D가 좌석에 없는 세션"에서 발생. 차익이 사라지는 게 아니라 **차익에 경쟁이 붙는다**.

### 3. 자금 소진 압력의 V2 재설계

004 원형(여유 = 잔액 − 남은 경매 수×30)은 폐기하고 2층으로 나눈다.

**런 층 (하루 단위, plan 외부):**

```
지갑 W        : 경쟁자별 런 지속. 초기값 = 단계 기준 세션 총출품가액 × 0.5~0.8
하루 지출률 ρ  : 브랜치별 0.4~0.7
세션 예산 B    = W × ρ × (1 + λ·(day/N))     # λ 0.5~1.0, 런 후반 "장이 끝나간다" 가속
환금(D만)     : 낙찰 t일 후 W += 기대전매가 × 노이즈(0.9~1.1)   # est_bot 기반, 실가치 비참조
단계 상승 시   : 캐스트 지갑 재기준 + 상위 격 NPC 1~2인 교체 진입
```

**세션 층 (004 공식의 상대화 — plan 시점):**

```
여유 = B_잔여 − 남은 출품 수 × 0.6·A_s        # A_s = 세션 카탈로그 est 중앙값
여유 > 0 이면 maxPay += 여유 / 남은 출품 수 × k   # k 0.2~0.3, 브랜치 계수로 증폭 (004 유지)
```

- "남은 경매 수"의 의미가 "이 단판의 잔여"에서 "이 세션의 잔여 출품"으로 바뀌고, 런 전체의 소진은 λ 가속과 환금 부재(수집형)가 담당.
- 주의(누설 차단): A3가 타인 잔액을 열람하므로, D의 환금액이 실제 가치 기반이면 지갑 변동에서 물건의 진짜 가치가 역산된다. 환금은 반드시 est_bot 기반 + 노이즈.

### 4. 상회 단계 연동

**단계 1~2 (MVP):**

- 스케일: 지갑·앵커 `A_s`·거래비용이 단계 기준 거래단위 `U_s`(§9.2: 수천→수만 G)에 비례. 산식은 전부 `A_s` 배수라 자동 추종.
- 격: 단계 2에서 캐스트에 상위 격 NPC 진입(지역 수집가 등 — 표현은 생성, 파라미터는 동일 트리). **노이즈 ±30%는 단계와 무관하게 유지** — "성향≠실력" 원칙(004)을 단계에도 적용해, 격 상승 = 지갑·취급 물건의 상승이지 감정 능력의 상승이 아니다.
- 플레이어 학습 보존: 단계 상승 시 캐스트 전원 교체가 아니라 1~2인 교체 — 읽어둔 경쟁자가 남아야 학습이 이월된다.

**왕립급 (최종 특별 경매, §12):**

| 축 | 일반 봇 | 왕립급 봇 |
|---|---|---|
| 동기 | 수집 or 전매 | **사용 극단** — 유물 자체가 목적. 전매 로직 없음 (유물은 환금 대상이 아님) |
| 구조 | 세션 반복 | **단판** — 004 소진 압력 원형이 여기서만 원형 그대로 재사용 가능 |
| 상한 캡 | est×1.5 | est×2.0 (임시) — 유물은 추정 범위가 공시되므로 캡 완화가 "바보" 인상을 안 줌 |
| 지갑 | 단계 기준 | 2옵션: (a) 엔딩 등급 고정 (b) 플레이어 최종 현금 ×0.6~1.4 밴드. **추천 (b)+엔딩 등급으로 밴드 중심 이동** — 낙찰 성패가 플레이어의 읽기에 걸리게. 고무줄 티가 나면 안 되므로 밴드 폭·노이즈는 E02 검증 대상 |
| 행동 | 브랜치별 | 점프 폭 큼, 패스 드묾, 이탈 늦음 — "왕실은 물러서지 않는다" (전부 plan 파라미터, 연출은 표현층) |

## 추천안에 대한 가장 강한 반론

**"뿌리 D는 저평가 발견이라는 핵심 재미(§1.3)의 자기파괴 장치다."** 전매형이 저평가 물건을 공정가−마진까지 정확히 받아치면, 플레이어가 안목으로 벌 수 있는 차익은 D의 추정 오차(±30%)와 D의 공석 세션에만 남는다. 그 잔여 마진이 "안목의 보상"으로 체감되기에 충분한지는 아무도 모른다 — 얇으면 게임의 1층 재미(싸게 살 수 있을까?)가 "D보다 운 좋게 추정하기"로 퇴화한다. 게다가 D의 밸런싱은 아직 수치가 없는 판매층 가격 함수에 통째로 의존하므로, 판매층이 흔들릴 때마다 D를 다시 맞춰야 하는 이중 밸런싱 부담이 런칭까지 계속된다.

### 차선안과 그 조건

차선은 **안 1 (최소 이식)**. 판매층 수치 확정이 늦어져 D의 산식 입력이 계속 공중에 떠 있거나, MVP 일정상 런 지갑·환금 시스템을 감당 못 하면 안1로 후퇴하고 D는 후속 결정으로 미룬다. 안2는 어떤 조건에서도 차선이 아니다 — 읽기 노이즈화 문제가 수치로 해결되지 않는 구조적 결함이기 때문.

## 추천이 뒤집히는 조건

1. **E02에서**: D 재적 세션의 플레이어 기대 차익률이 임계(임시: 매입가 대비 15%) 아래로 떨어지고, 노이즈·공석 조정으로도 회복 안 될 때 → D 약화 또는 안1 후퇴.
2. **E02에서**: 수집형 봇의 런 종료 지갑 잔액이 여전히 초기값의 70%+ (임시)로 남을 때 → 소진 재설계 자체가 실패, 2층 공식 재검토.
3. **플레이테스트에서**: D가 좌석에 있으면 다른 뿌리의 시그니처가 안 읽혀 "3~4판 뿌리 구분"이 실패할 때 → 좌석 규칙 변경(D 등장률 인하) 또는 안1 후퇴.
4. **판매층 설계에서**: 구매자별 제안가 함수가 봇이 재사용할 수 없는 형태(플레이어 전용 상태 의존)로 확정될 때 → D 산식의 전제 붕괴.
5. **하루 사이클 설계에서**: 세션당 출품 수가 극소(1~2개)로 확정될 때 → 세션 층 압력 공식이 무의미해져 런 층 단독 공식으로 재설계.

## 아직 결정할 수 없는 질문

- 플레이어 보관품의 봇 공개 여부 (타인 보유 읽기의 V2 범위) — 스펙 §7 보관 설계에 종속.
- 캐스트 규모·좌석 수 — 하루 사이클(§3.2 미정)에 종속.
- 왕립 지갑 밴드의 고무줄 체감 여부 — E02 + 플레이테스트 병행 검증.

## 후속 (사람 승인 후)

이 문서는 결정 문서가 아니다. 승인 시: ① 결정 문서(007 후보) 작성 ② E02 시뮬레이터에 §6 파라미터 반영 ③ 스펙 §5 경쟁자 조항 개정 태스크 — 보드에서 분해.
