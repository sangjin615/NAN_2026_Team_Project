## 0. 공통 전제 (모든 후보안이 공유)

### 0.1 불변 제약 (위반 시 제출 불가)

1. 봇은 추리 정답 대상이 아니라 경제적 압력. 성향은 읽히되 확신되지 않는다.
2. 경매 중 생성 모델 호출 금지. "동기"는 런 시작 시 생성된 표현, 행동은 전부 알고리즘 파라미터.
3. 봇 계획(maxPay·interest)은 경매 시작 전 plan 시점 고정. 경매 중 반응형 재계산 금지.
4. 과입찰 상한 캡(004) 유지 — 봇이 바보로 보이면 안 됨.
5. 봇 행동이 숨은 태그·실제 가치를 직접 누설하지 않는다.

|---|---|---|
| 뿌리 A1 정석형 (maxPay=est) | **유효** | 스케일 무관. 기준선 봇으로 그대로. |
| 뿌리 A2 저격형 (TIER_MID 초과만 ×1.1) | **수정** | 로직 유효하나 TIER 절대값(≤20/22~38/≥40)이 V1 소액 경제 기준. 단계별 상대 앵커로 재기준 필요. |

| 뿌리 B2 링크형 (ownerLinkIds 보너스) | **유효** | V2도 소유자 전용 정보·출처를 계승(§5). 생성 파이프라인이 링크를 유지하는 조건부. |

| 뿌리 C2 추세형 (직전 3~4건 낙찰가 비율) | **유효(강화)** | 반복 경매·시장 변동 사건이 있는 V2에서 오히려 더 의미 있음. 윈도우가 며칠에 걸칠 수 있게 확장. |
| 뿌리 C3 역발상형 (유찰 누적 시 상향) | **유효** | 유찰·재경매 규칙은 V1 기본값 유지(§5). |
| 공통: 소진 압력 공식 (잔액 − 남은 경매 수×30) | **폐기·재설계** | "남은 경매 수"가 단판 전제. 앵커 30도 V1 절대값. → 본 문서의 핵심 재설계 대상 (각 안 참조). |
| 공통: 상한 캡 maxPay ≤ est×1.5 | **유효(근거 교체)** | 캡 자체는 불변 제약. 단 004의 근거 "§14.3 동률 불리"는 V1 점수식 → 폐기. 새 근거: 전매 마진 붕괴 방지 + 봇이 바보로 보이면 안 됨. |
| 공통: 타인 보유 겹침 읽기 (A3·B3 견제 / C3 회피) | **수정** | 세트 조각 프레임 → 계열 프리미엄 프레임. 플레이어 보관품(§7)이 공개 정보인지 V2 미정 — 공개 범위 확정 전까지 "직전 낙찰 이력"만 읽는 보수 버전으로. |
| 공통: 점프 파라미터화 (plan으로 이동) | **유효** | 그대로. |
| 공통: interest ≠ maxPay 분리 | **유효** | 그대로. 동기 표현층의 판정측 대응물로 중요도 상승. |
| 공통: 추정 노이즈 ±30% 균일 (성향≠실력) | **유효** | 상대값이므로 스케일 무관. |
| 시드 선택 "서로 다른 뿌리 3개" | **수정** | 단판 전제(판마다 3봇 생성). V2는 런 시작 시 경쟁자 캐스트를 생성하고 세션마다 좌석 배정하는 구조로 — 플레이어가 여러 판에 걸쳐 같은 경쟁자를 학습해야 "3~4판 안에 뿌리 구분" 가설이 성립. |
| 메타루프(003) 연계 조항 | **폐기** | 003은 006이 대체. |

### 0.4 공통 신규 장치 (모든 후보안이 채택)

- **런 캐스트**: 런 시작 시 경쟁자 NPC 4~6인(임시)을 생성. 각자 뿌리·브랜치·동기 원형·런 지속 지갑을 가짐. 세션마다 3좌석 배정.
- **단계 상대 앵커 `A_s`**: 해당 세션 카탈로그의 추정가 중앙값(또는 상회 단계 s의 기준 거래단위 `U_s`). 모든 공식은 `A_s` 배수로 정의 — E02 시뮬레이터에서 무차원 파라미터로 테스트 가능.
- **동기 ↔ 파라미터 매핑**: 엔진이 먼저 (뿌리·브랜치·관심 태그) 조합을 확정하고, AI는 그 조합에 조건화된 동기 텍스트만 생성. 역방향(텍스트→파라미터 해석) 금지. 상세 표는 recommendation 문서.

## 후보안 1 — 수직 이식 최소안 ("004 그대로, 스케일만")

### 설계

- 뿌리 3 × 브랜치 3 유지. §0.3의 수정 항목만 반영(앵커 상대화, 세트→계열 프레임 교체).
- 전매 동기는 별도 봇이 아니라 **C2 추세형의 수치 강화**로 흉내: 시장 온도가 낮을 때(직전 낙찰가/추정 비율 낮음) 기준가를 올려 저평가 물건에 압력.
- 봇 지갑은 **세션 스코프**: 세션 시작 시 단계별 예산 지급, 세션 끝나면 리셋. 소진 압력은 004 공식의 앵커만 교체: 여유 = 세션 예산 − 남은 출품 수 × 0.6·A_s (0.6 임시).
- 왕립급 봇 = 일반 봇의 지갑·캡 확대판.

### 장점

- 구현 비용 최소. 기존 computeBotPlan 파이프라인에 앵커 치환만.
- 004에서 검증하려던 회귀 테스트 자산(27조합) 재사용.
- E02 시뮬레이터 연결이 가장 빠름.

### 약점

- **"팔려고 사는 자"가 없다.** 설계 과제 2를 회피 — 저평가 물건에서 플레이어와 경쟁하는 압력이 구조적으로 약함. "가치 불문 매수" 억제를 C2 수치 하나에 의존.
- 세션 스코프 지갑이라 **"봇이 런 종료 시 자금을 유의미하게 소진한다" 가설을 정의조차 못 함** — 세션마다 리셋되는 지갑에 '런 종료 잔액'이 없다.
- 동기 텍스트가 파라미터와 느슨하게만 연결 — "특정 물건에 집착하는 이유"(§5) 표현이 행동과 어긋날 위험.
- 반복 경매에서 봇이 학습·변화 없이 동일 패턴 → 런 중반부터 압력이 읽혀 무력화.

### 구현 비용

낮음 (앵커 치환 + 계열 프레임 교체. 신규 시스템 없음)

## 후보안 2 — 동기 직교축 추가안 (뿌리 3 × 브랜치 3 × 동기 2 = 18변종)

### 설계

- 004 트리(가치평가 소스)는 유지하고, **직교하는 동기 축**을 추가: 모든 봇이 수집형(쓰려고 삼) 또는 전매형(팔려고 삼) 동기를 가짐.
- 수집형 maxPay = 기존 004 공식 (est 기반 + 동기 태그 가산).
- 전매형 maxPay = 전매 기대가 기반:
  - `기대 전매가 = est_bot × 계열온도(임시 0.8~1.3) `
  - `maxPay = 기대 전매가 × (1 − 목표마진) − 예상 거래비용` (목표마진 임시 0.15~0.25)
- 봇 지갑은 **런 지속**: 전매형은 낙찰품을 오프스크린 환금(1~2일 후, est_bot 기반 — 실제 가치 비참조로 누설 차단)해 지갑 회전. 수집형은 안 팔아 실소진.

### 장점

- 설계 과제 2를 정면으로 해결. 어떤 뿌리든 전매형이 될 수 있어 세계 표현이 풍부("계열 전문 전매상" = B1×전매 등).
- 저평가 물건마다 전매형이 공정가 근처까지 받아쳐 "가치 불문 매수" 억제가 구조적.
- 런 지갑으로 소진 가설 정의 가능.

### 약점

- **004가 자유 조합을 기각한 이유(뿌리 읽기 노이즈화)를 정면으로 재도입.** 동기 축은 행동에 가장 크게 드러나는 축이다 — 전매형 B1과 수집형 B1은 완전히 다르게 행동하므로, 플레이어가 읽는 것은 사실상 동기이지 뿌리가 아니게 됨. "3~4판 안에 뿌리 구분" 가설이 위태로움.
- 18변종 밸런싱·회귀 시드 부담 (27조합 문제의 악화판).
- 뿌리(평가 소스)와 동기(maxPay 산식)가 이중 산식이라 plan 코드 복잡도 최대.

### 구현 비용

높음 (이중 산식 + 런 지갑 + 오프스크린 환금 + 18변종 밸런싱)

## 후보안 3 — 전매 뿌리 신설안 (뿌리 4 × 브랜치 3 = 12변종, 좌석은 "서로 다른 뿌리 3")

### 설계

004의 트리 철학을 유지한다: **뿌리 = 행동에 가장 크게 드러나는 축**. V2에서 새로 생긴 가장 큰 행동 축은 "왜 사는가"이므로, 전매를 직교축이 아니라 **네 번째 뿌리 D**로 신설하고 A·B·C는 수집 동기로 고정한다.

#### 뿌리 D — 전매형 (소스: 전매 기대 이익)

공통 산식 (수치 전부 임시):

```
기대전매가 = est_bot × 계열온도                # 계열온도: 공개 시장 신호 기반 0.8~1.3
maxPay    = 기대전매가 × (1 − 목표마진) − 거래비용
           (항상 캡 est_bot × 1.5 이하)
```

- D1 **마진 고정형**: 목표마진 0.20 고정. 어떤 물건이든 마진 라인에서 칼같이 이탈. 가장 읽기 쉬운 전매상 — 기준선.
- D2 **회전율형**: 목표마진 0.10으로 얇게, 대신 interest 광범위(싼 물건 다수 노림). 오프스크린 환금 주기 짧음(1일). 저가대 물건 전반에 상시 압력.
- D3 **매점형**: 특정 계열 하나에 목표마진 −0.05~0(원가 매입 불사), 해당 계열 외 interest 최저. 계열을 모아 일괄 판매 프리미엄(§7)으로 환금 — 환금 배수 큼(임시 ×1.3), 대신 환금 지연 큼(3일+). 플레이어의 컬렉션 전략과 정면 충돌하는 압력.

#### 지갑·소진 압력 (Q3 재설계 — recommendation에 상세)

- 런 지속 지갑 + 하루 지출 성향 ρ로 세션 예산 산출, 세션 내 압력은 004 공식의 상대화 버전.
- A·B·C(수집형)는 환금 없음 → 런 종료 시 실소진. D는 환금 회전 → 런 내내 지속 압력.

#### 좌석 규칙

- 런 캐스트에서 세션마다 "서로 다른 뿌리 3개" 배정 (4택3). D는 세션의 약 3/4에 등장(임시) — 상시 감시자가 아니라 "자주 마주치는 경쟁 상인".

### 장점

- 설계 과제 2를 해결하면서 **004의 핵심 통찰(뿌리는 읽히되 브랜치는 확신 못 함)을 보존**. 전매형의 행동 시그니처(마진 라인 칼 이탈, 저평가에서만 등장, est 초과 과열 없음)는 뿌리 판별 단서로 오히려 가장 선명.
- 4택3 좌석이라 전매 압력이 "항상"이 아니라 "대체로" — 전매형이 빠진 세션이 플레이어의 숨통(대박 기회)이 되어 세션 간 리듬 생성.
- 12변종으로 안2(18)보다 밸런싱 부담 작고, 브랜치 3종이 각각 다른 층(고가 단품/저가 다량/계열 매점)을 압박해 압력 커버리지가 넓음.
- D3 매점형이 §7 일괄 판매 프리미엄의 판정측 대응물 — 세계 규칙과 봇 행동이 같은 경제 논리를 공유.

### 약점

- 전매 산식이 판매층 가격 함수(계열온도·환금 배수)에 의존 — **판매층 수치가 확정되기 전에는 D의 밸런싱이 공중에 뜬다.** E02에서 판매층 모델을 봇에도 돌려야 함.
- 전매형이 저평가를 정확히 받아치면 플레이어의 차익 마진 자체가 사라질 위험 — "저평가 발견" 재미를 죽이는 자기파괴 가능성 (노이즈 ±30%와 4택3 공석이 완충이지만 시뮬 검증 필수).
- 뿌리 4종이 되며 "서로 다른 뿌리 3개" 조합이 4가지 → 회귀 시드 소폭 확대.

### 구현 비용

중간 (신규 뿌리 1종 + 런 지갑 + 오프스크린 환금. 이중 산식은 D에 국한되어 안2보다 단순)
