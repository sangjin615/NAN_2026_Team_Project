# V2 봇 트리 한눈에 보기 — 사람용 참조 자료

- 상태: 브레인스토밍 산출물의 **요약 참조**. 판정 근거는 comparison·recommendation·information-model·value-model 4문서. 충돌 시 그쪽이 정본.
- 수치 표기 원칙: **모든 수치는 밸런싱 대상 임시값.**
- 작성일: 2026-07-21

---

## 봇 한 마리의 조립 공식

```
봇 = ① 뿌리 × 브랜치 (시장축 기질 — est를 어떻게 다루나)
   + ② 사정 배정   (사정축 — est와 무관한 개인 사정 가격)
   + ③ 신분        (단골 / 뜨내기 / 숙적 / 왕립급)
   + ④ 지갑        (런 지속, 단계 연동)

동기 텍스트(AI 생성) = ① + ②의 문학적 표면. 엔진이 먼저, 텍스트는 나중.
maxPay = max(시장축, 사정축).  캡: 시장축 est×1.5 / 사정축 절대액 자체.
```

## 전체 트리

```
미지의 경매장 V2 — 경쟁자 트리 (뿌리 4 × 브랜치 3 = 12기질)

A 자기 추정 신뢰형 ─┬─ A1 정석형      "내 눈은 틀린 적이 없소"
  (시장축 지배)     ├─ A2 저격형      "이류에는 흥미 없소"
                    └─ A3 관리형      "주인님의 예산은 엄격합니다"

B 관계 추적형 ──────┬─ B1 주제 수집가 "바다와 관련된 것이라면 무엇이든"
  (사정축 지배)     ├─ B2 가문 회수인 "그건 원래 우리 가문 것이오"
                    └─ B3 완벽주의자  "이번엔 반드시 전부 모은다"

C 시장·공개정보형 ──┬─ C1 관망가      "값은 세상이 정하지"
  (시장축 지배)     ├─ C2 투기꾼      "요즘 이게 뜬다더군"
                    └─ C3 역발상가    "남들이 버릴 때 줍는 법"

D 전매형 ───────────┬─ D1 견실 중개상 "이문이 두 할은 남아야"
  (중간·출구 기반)  ├─ D2 박리다매    "싸게 많이, 빨리 돌린다"
                    └─ D3 매점꾼      "이 계열은 전부 내 것이 될 거요"

좌석: 세션당 3석 = 단골 2 + 뜨내기 1 (임시). 서로 다른 뿌리 3개 (4택3).
```

## 뿌리 A — 자기 추정 신뢰형

시장축 지배. 자기 est_bot을 믿고 물건 불문 일관되게 지른다. 출처: 004 직계.

| 브랜치 | 행동 (판정) | 유저 눈에 보이는 것 | 상태 |
|---|---|---|---|
| A1 정석형 | maxPay = est_bot. 점프 없음 | 어떤 물건이든 비슷한 선에서 멈춤. 재경매에서 상한 재현 | 004 유효 |
| A2 저격형 | 고티어만 est×1.1, 나머지 ×0.8. interest 선점, 점프 크고 잦음 | 비싼 것에만 눈빛이 변함. 싸구려엔 심드렁 | 004 수정 (티어를 단계 상대 앵커로) |
| A3 관리형 | 예산 상한 + 타인 잔액 열람. 경쟁자 평균 잔액이 자기보다 낮으면 상한 해제. 계열 겹침 견제 가산 | 평소 짜다가, 판이 가난해지면 갑자기 대담해짐 | 004 수정 (견제를 세트 조각 → 계열 프리미엄 프레임으로) |

**뿌리 판별 단서**: 물건을 안 가리고 자기 기준에 일관. / **확신을 막는 것**: 노이즈 ±30%, 브랜치별 티어 편향.

---

## 뿌리 B — 관계 추적형

**사정축 지배 — 2축화의 주역.** est보다 개인적 의미(키워드·소유자 링크)가 가격을 정한다. 단골로 배정 시 사정 아크(지속→충족→퇴장)의 주인공. 출처: 004 직계 + value-model 사정축.

| 브랜치 | 행동 (판정) | 유저 눈에 보이는 것 | 상태 |
|---|---|---|---|
| B1 주제 수집가 | 관심 계열 키워드 겹침에 보너스 (조건형 사정) | 특정 주제 물건에서만 과열. 주제는 관찰로 좁혀야 함 | 004 수정 (보너스 근거: 세트 완성 → 일괄 판매 프리미엄) |
| B2 가문 회수인 | ownerLink 물건에 지정형 사정 절대액. 해당 물건 interest 최대 | 특정 출처 물건에 est 무관한 집착. **충족되면 조용해짐 (아크)** | 004 유효 + 사정축 신규 |
| B3 완벽주의자 | 계열 첫 획득 전 interest 최대 + est×1.0. 계열 잔여 출품 소진 임박 시 ×0.7 급락. 견제 | 초반에 사납다가 어느 순간 식음. 남의 수집도 방해 | 004 수정 (데드라인: 판 절반 → 계열 잔여 출품 수) |

**뿌리 판별 단서**: 특정 계열·출처에서만 무리한다. / **확신을 막는 것**: 어떤 계열/링크인지는 축적 관찰 필요.

---

## 뿌리 C — 시장·공개정보형

시장축 지배. 자기 눈이 아니라 시장의 눈을 믿는다. 반복 경매 구조에서 가장 수혜. 출처: 004 직계.

| 브랜치 | 행동 (판정) | 유저 눈에 보이는 것 | 상태 |
|---|---|---|---|
| C1 관망가 | 티어 중앙값 + 공개문장 가중 | 무난한 선. 화려한 설명에 약간 약함 | 004 수정 (스케일만) |
| C2 투기꾼 | 직전 3~4건 (낙찰가/기준) 비율을 기준가에 곱함. 점프 확률 시장 온도 연동 | 장이 뜨거우면 같이 뜨거워짐. 세션 간 상한 이동 | 004 유효·강화 (윈도우 며칠로 확장) |
| C3 역발상가 | 유찰·저가 낙찰 누적 시 기준 상향. 재경매 계수 유일하게 ×1.05. 경합 예상 물건 회피 | 남들이 외면한 물건을 줍고, 붐비는 곳엔 없음 | 004 유효 |

**뿌리 판별 단서**: 상한이 시장 흐름 따라 세션 간에 움직인다. / **확신을 막는 것**: 추세인지 역발상인지 초반 혼동.

---

## 뿌리 D — 전매형 (V2 신규)

출구 기반 — 유일하게 유저와 같은 꼴의 산식(팔 값에서 역산). 저평가 물건에서 유저의 직접 경쟁자. 마진 라인에서 칼같이 이탈하고, est를 넘는 과열이 없다. 출처: recommendation 신규.

```
maxPay = est_bot × 계열온도(0.8~1.3) × (1 − 목표마진) − 거래비용   [캡 est×1.5]
```

| 브랜치 | 목표마진 | 행동 (판정) | 유저 눈에 보이는 것 | 
|---|---|---|---|
| D1 견실 중개상 | 0.20 고정 | 어떤 물건이든 마진 라인 이탈. 환금 2일 | 가장 읽기 쉬운 벽. "쟤가 빠진 가격 = 시세의 8할" |
| D2 박리다매 | 0.10 | interest 광범위(저가 다수), 환금 1일 | 싼 물건마다 어른거림. 얕지만 넓은 압력 |
| D3 매점꾼 | 0±0.05 (한 계열만) | 지정 계열 원가 매입 불사, 일괄 환금 ×1.3(지연 3일+). 그 외 무관심 | 한 계열을 쓸어 담음. 유저의 컬렉션 전략과 정면 충돌 |

**뿌리 판별 단서**: 칼 이탈, est 초과 없음, 저평가에서만 등장. / **확신을 막는 것**: 마진 폭·매점 계열은 브랜치 따라 다름.

## 사정축 배정 (뿌리와 독립)

| 유형 | 내용 | 배정 대상 |
|---|---|---|
| 지정형 | 특정 물건·링크에 절대액 ("저 반지에 8,000G") | 단골만 — 아크 성립 |
| 조건형 | 태그·계열 조건에 절대액 ("바다 키워드면 5,000까지") | 단골·뜨내기 |
| 기한형 (납기 상인) | 계약가 + 기한. day 임박 시 과열 계수 | 의뢰 경로의 압력 짝 |

절대액은 **실가치 비참조 독립 추첨** (A_s 배수, 임시 1~3×). 엔진 상태는 (대상/조건, 절대액, 충족 플래그, 기한) 4개뿐 — 비하인드는 전부 표현.

## 신분

| 신분 | 정의 | 역할 |
|---|---|---|
| 단골 | 런 캐스트 핵심 3~4인, 런 내내 유지 | 프로파일링 대상 ("3~4판 뿌리 구분" 가설의 적용 범위), 사정 아크 |
| 뜨내기 | 세션 1회성. 같은 트리에서 생성, 축적 관찰 불가 | 역선택 공포 보존 — 단골을 다 읽어도 남는 불확실성 |
| 숙적 | 단골의 극단, 1인, 단계 2부터(임시) | 공표된 강함: 정보 폭 전체 + 노이즈 ±15% + 지갑 최대 + 리드 식별(유일 허용). 도전과제 "3연승"의 짝 |
| 왕립급 | 최종 특별 경매 전용 | 사정축 극단(유물 그 자체가 목적). 캡 est×2.0, 소진 압력 004 원형(단판), 패스 드묾 |

## 이 장표의 사용법

밸런싱 회의·플레이테스트 브리핑에서 "이 봇 누구야?"에 답하는 용도. 산식 상세·근거·반론은 4문서 체인 참조:
`comparison`(후보 비교·004 승계 판정) → `recommendation`(산식·매핑 표·E02 파라미터) → `information-model`(입력 인벤토리·유저 사고) → `value-model`(2축 가치·스코프·확정 사항).
