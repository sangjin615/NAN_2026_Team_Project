## 1. 가치 비대칭 — 이 게임의 정의

**봇의 가치는 실가치에 닻을 내리고(est_bot), 유저의 가치는 출구에 닻을 내린다(경로 최대값).** 이 간극이 버그가 아니라 수익의 원천이다: 봇이 est까지 받아쳐 낙찰가를 실가치 근처로 수렴시키고, 유저의 이윤은 "나만 아는 출구 가격"과 실가치의 차이에서 나온다.

**최종 특별 경매는 이 비대칭이 소멸하는 유일한 순간이다.** 유물은 팔 수 없고(영구 소장) 런이 끝나 돈의 미래 가치도 없다. 유저와 봇 모두 "그 자체가 목적"이 되어 가치 체계가 수렴하고, 순수한 지갑+읽기 대결만 남는다. 왕립급 봇에 경로 로직이 불필요한 이유이자, 최종 경매가 클라이맥스로 느껴지는 구조적 이유.

### 1.1 경로 커버리지 원칙(안)

유저의 경로 가치가 봇의 est를 크게 넘는 물건일수록 경합이 사라진다 — 유저가 가장 간절한 물건에서 봇이 가장 무기력해지는 구조적 위험. 프로토타입의 의뢰 지배 = "의뢰 경로에 압력 짝이 없었다".

> **유저가 수익을 낼 수 있는 모든 경로에는, 그 경로의 가치를 근사하는 봇 압력이 최소 하나 존재해야 한다. 봇은 유저의 실제 경로를 훔쳐보지 않고(치팅 금지), 읽을 수 있는 동기로 근사한다.**

| 유저 경로 | 압력 짝 | 상태 |
|---|---|---|
| 자유 판매 | 뿌리 D 전매형 (기대전매가 — 유일하게 유저와 같은 꼴의 출구 기반 산식) | 설계됨 (recommendation) |
| 세트 일괄 | D3 매점형 + A3·B3 견제 (유저 보유 읽기 → 필요 조각 가산) | **성립 — §6.2 보관품 공개 확정으로 전제 충족** |
| 의뢰 납품 | "납기 상인" 동기 원형 (사정축 순수형, §3) | 제안됨 |

## 2. 봇 스코프 사다리

> **스코프 개방 기준(안)**: 봇 스코프 확장은 ① 유저가 관찰할 표면을 늘리고(가독성), ② 기존 엔진 상태(지갑·동기 태그·est_bot·사정축)만 소비하며, ③ **봇에게 새로운 의사결정 루프를 만들지 않을 때만** 연다. 봇의 삶은 넓어져도 봇의 뇌는 커지지 않는다.

| 레벨 | 내용 | 판정 |
|---|---|---|
| L0 경매장 바닥 | 입찰·지갑·동기 (002 기준선) | 확정 |
| L1 흔적 | 봇 낙찰의 세계 반영 — D의 낙찰품이 며칠 뒤 거래소에 마진 붙어 진열(유저가 패배의 기회비용을 목격), 매점 계열의 시장 온도 상승. 새 의사결정 없음 | **개방** (비용 대비 가독성 최고) |
| L2 구매자 | 경쟁자=구매자 통합 — 봇이 거래소에 구매자로 등장, 취향=동기 태그·사정축, 제안가=est_bot 기반(누설 차단 유지). 구매 한도·관심 임계값으로 쓰레기 처분 착취 차단 | **개방** (§15 MVP의 거래소와 호환). 지갑은 §6.1에 따라 비연동 |
| L3 소문 | 사건·술집이 봇 엔진 상태를 읽어 표현 ("자금난이라더라", "도자기를 쓸어 담는다더군"). 숙적의 "공표된 강함"이 얹히는 층 | 후속 (술집이 MVP 제외) — 훅만 설계 예약 |
| L4 시뮬레이션 | 봇이 자기 상회를 성장시키는 경쟁 상회 | **기각 (2026-07-21 확정)** — 기준 ③ 위반, E02 검증 불가. 경쟁 상회 서사가 필요하면 L3 표현으로 대체 |

## 3. 봇 가치의 2축화

### 3.1 문제 — est 앵커의 구조적 누설

004~002의 봇은 전원 est 앵커(공통가치 입찰자)다. 봇 하나의 노이즈는 ±30%지만 세 마리의 입찰을 겹치면 노이즈가 평균으로 씻겨 **군중의 지혜로 실가치가 샌다.** "쟤 왜 저래?"의 두 답(동기 vs 가치)이 사실상 가치 쪽으로 기울어 있었다.

### 3.2 설계 — 시장축 + 사정축

모든 봇의 maxPay = **max(시장축, 사정축)**:

| 축 | 산식 | 실가치와의 관계 | 캡 |
|---|---|---|---|
| 시장축 | est_bot × 브랜치 수정자 (현행 002) | 상관 (노이즈 ±30%) | est_bot × 1.5 (004 유지) |
| 사정축 | 런 시작 생성 시 배정된 **절대액** — "가문의 예산 8,000G", "납품 계약가", "이 계열이면 무조건 X까지" | **무상관 — 절대액은 실가치를 참조하지 않고 앵커 A_s 배수 분포에서 독립 추첨** | 배정 절대액 자체가 캡 |

**캡 분리는 불변 제약(004 상한 캡)의 형태 개정이다**: 원칙의 목적("봇이 바보로 보이면 안 됨")은 유지 — 가문의 반지에 est 3배를 내는 봇은 동기가 표현되는 한 바보가 아니라 캐릭터다. 사정축에도 절대액 캡이 있어 무한 과열은 불가. 결정 문서 승격 시 이 개정을 명시할 것.

### 3.3 효과

- **누설 차단**: 사정축 입찰이 시장 신호에 실가치와 무관한 잡음을 섞는다. 봇 관찰 종합으로 실가치를 역산할 수 없게 됨.
- **herding 처벌**: 사정축 봇의 과열을 "진짜 좋은 물건 신호"로 읽고 따라 붙은 유저는 물린다 — "봇 따라 사기"가 전략이 못 되게 게임이 스스로 가르침.
- **프로파일링 보상의 정밀화**: 저 과열이 사정인지 가치인지는 그 봇의 동기를 읽은 자만 구분한다.
- **핍진성**: 런 내내 유지되는 경쟁자는 사람으로 지각된다. 사람에게는 비하인드가 있고, 비하인드가 있는 사람이 이상한 물건에 돈을 쓰는 것이 오히려 현실적이다. **기능과 핍진성이 같은 방향을 가리킨다.**

### 3.4 트리 매핑 (스펙트럼)

A·C 시장축 지배 / B 사정축 지배(가문·집착) / 납기 상인 순수 사정축 / D 중간(기대전매가는 est 앵커라 완전 무상관 아님) / 왕립급 사정축 극단(유물 그 자체).

### 3.5 스토리-가격 동일성 규칙

**스토리와 가격은 같은 사실이다.** 엔진이 (대상/조건, 절대액, 기한)을 먼저 확정하고, AI 비하인드 텍스트는 거기 조건화되어 생성된다. 역방향 금지. 비하인드가 아무리 길어도 **엔진에 사는 것은 (대상/조건, 절대액, 충족 플래그, 기한) 뿐** — 핍진성 논리의 L4 회귀(스코프 무한 확장)를 이 규칙으로 차단한다.

### 3.6 사정의 아크 (단골 전용)

| 국면 | 행동 | 의미 |
|---|---|---|
| 지속 | 사정 대상이 나올 때마다 무리한다 | 유저가 2~3회 관찰로 읽는 프로파일 재료 |
| 충족 | 대상 획득 → 사정축 소멸, 시장축만 남아 행동이 눈에 띄게 변화 | **입찰 행동만으로 서사의 장이 넘어감** + 그의 압력 소멸이라는 시장 변화 |
| 퇴장(선택) | 목적을 이룬 단골이 캐스트에서 이탈 | 캐스트 교체의 서사적 정당화 ("그는 원하는 걸 얻었다") |

배정 방식: **단골 = 지정형(특정 물건·링크 — 아크 성립) + 조건형(취향) 혼합 / 뜨내기 = 조건형만(1회성 사정).**

## 4. 지갑 소모전 (유저 → 봇 방향의 심리전)

지갑이 런 지속이므로, 유저는 단골의 사정 대상을 호가로 띄워 비싸게 사게 만들어 다음 세션의 그를 가난하게 만들 수 있다. 실패 시 유저가 그 물건을 떠안는 위험이 자동 밸런스. Tier 3 논의에서 "유저가 봇을 읽는 방향으로 보존"하기로 한 낚시 재미의 구현이다. **§6.1 결정에 따라 소모전의 통로는 경매장뿐이다** (거래소 판매로는 봇 지갑을 건드릴 수 없음).

## 5. 봇 입력 인벤토리 갱신 (information-model §2 개정)

**결론: 2축화는 봇의 세계 입력을 하나도 늘리지 않는다. 늘어나는 것은 자기 상태뿐이다.** (스코프 기준 ②의 검산)

- 물건·시장·참가자 입력: 변경 없음. 사정축 지정형은 카탈로그 물건 ID 매칭, 조건형은 공개 키워드 매칭 — 원래 읽던 것.
- 자기 상태 신규 4종: **사정 대상/조건, 사정 절대액, 충족 플래그, 사정 기한**(납기형만, day/N 읽기).
- L2 구매자 역: 유저 매물의 공개 정보 + est_bot + 동기 태그·사정축 + 구매 한도 — 전부 기존 입력 재사용.

### 5.1 신규 금지 범주 — 생성 시점 금지

기존 금지는 전부 런타임이었다. 2축화가 새 범주를 만든다:

> **사정 절대액 추첨 시 대상 물건의 실가치 참조 금지.** (생성 파이프라인 검증 하네스 항목)

깨지면 사정축이 몰래 실가치와 상관되어 무상관이라는 존재 이유가 무너진다. 지정형에서 특히 위험 — "귀한 반지니까 사정액도 높게"의 유혹을 생성기가 받는다.

## 6. 확정 사항 (2026-07-21, 최재혁)

### 6.1 거래소 지갑 비연동

L2에서 유저가 봇에게 팔아도 봇의 런 지갑(경매 지갑)은 줄지 않는다. 거래소 구매 자금은 무대 밖(압력 함수 원칙 — 봇의 오프스크린 삶은 허구)으로 처리.

- 근거: 연동 시 "팔아서 약화시키기"가 열리지만, 경매 압력의 상태인 지갑이 판매층 밸런스에 종속되는 결합이 생긴다. 우선 비연동으로 단순하게.
- 정합성 처리: 잔액 UI는 "경매 예산"으로 라벨링해 무대 밖 자금과 구분.
- **재검토 조건**: 플레이테스트에서 "팔았는데 그놈이 여전히 부자"가 불쾌감으로 보고되면 연동 재검토.

### 6.2 유저 보관품의 봇 공개 — 공개로 확정 (기본값)

- 근거: 경로 커버리지 원칙 — 비공개면 세트 마지막 조각이 항상 무경합이 되어 세트 경로가 지배 경로화. 004의 견제 메커니즘(A3·B3)이 이 공개를 전제.
- information-model §2.2·§4.4의 해당 미정 항목은 이 확정으로 해소.
- UI 표시 수준(전시 형태 등)은 별도 — 판매층 설계에서.

## 7. 열린 질문 (갱신)

**봇 트랙:**

- 사정 절대액의 추첨 분포 (A_s 배수 범위 — 임시 1~3×A_s 후보)
- 단골당 사정 개수 (지정형 1 + 조건형 1이 기본값 후보)
- 충족 후 퇴장 확률·시점, L1 진열가 규칙 (D 마진 반영 폭)
- L2 구매 한도·관심 임계값 (쓰레기 처분 착취 차단선)

**경제 트랙 이관 (기존 목록에 추가):**

- L1 진열이 유저 판매층 가격에 미치는 영향 (봇 진열품과 유저 매물의 경쟁 여부)

**검증 항목 추가 (E02·플레이테스트):**

- 사정축 혼입 후에도 봇 3좌석 입찰 종합으로 실가치 추정이 가능한가 (누설 회귀 테스트 — 상관계수 상한 설정)
- herding 시도가 실제로 처벌되는가 / 처벌이 과도해 봇 관찰 자체가 무의미해지지 않는가
- 사정 아크(충족 후 변화)를 유저가 인지하는가
