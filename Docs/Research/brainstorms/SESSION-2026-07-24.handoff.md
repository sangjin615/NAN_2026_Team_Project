## 다음 목표 — 시뮬을 team-loop에 연결한 밸런싱 (합의된 방향)

오늘 시뮬은 손으로 돌린 맛보기. 본 밸런싱은 보드 루프로:

1. **시뮬에 `--assert` 모드 추가**: K03 기준(누설 잔차 ≤0.3 / 수집형 소진 ≤20% / fair>blind 서열 / 무경합 상한 / 후반 유저 점유 하한)을 코드로 박아 exit 0/1 판정화. 판정은 프로그램 원칙 그대로.
2. **team-loop 검증 프로필 등록**: `balance-gate` 프로필 = sim --assert 2종(캐스트·거래소) + 기존 회귀. 밸런스 값 변경 태스크는 이 프로필로 verify.
3. **노브 스윕 = 보드 태스크**: 스윕 실행(제안 프리미엄 1.05~1.25 / 계열 밀도 / 성장 스케줄 후반 수치)을 태스크 단위로 claim→worktree→스윕→기준 판정→리뷰. 결과 수치는 findings 문서로 축적.
4. 실패 사례는 team-loop 실패 학습으로: 기준 미달 스윕 결과 → 하네스/스킬 승격 루프 재사용.
