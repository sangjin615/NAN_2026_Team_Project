# 브레인스토밍 결과 — 001 핵심 재미

> 상태: 기존 시안(Baseline). 이 문서는 정답이나 최종 결정이 아니며 신규 후보 5개가 독립적으로 작성된 후 비교 대상으로만 사용한다.

## 1. 핵심 재미 한 문장

전체 카탈로그를 보고 숨은 가치와 관계를 추론한 뒤, 경쟁자가 만드는 가격 압력 속에서 미래 기회를 포기하거나 지키며 제한된 자본을 배분하는 재미.

## 2. 핵심 루프

`카탈로그 관찰 → 가치·세트 가설 → 자금 계획 → 추가 정보 확인 → 공개 호가 → 경쟁 또는 포기 → 결과 축적 → 가설 수정 → 최종 공개`

## 3. 플레이어의 중심 판단

플레이어가 반복해서 내려야 하는 질문은 다음이다.

> “이 물건이 좋은가?”보다 “이 물건을 이 가격에 사는 것이 남은 전체 경매를 고려해 좋은가?”

각 경매의 판단 요소:

- 현재 물건의 추정 실제 가치
- 세트 구성 가능성
- 부분 세트 또는 완성 세트 보너스
- 현재 낙찰 가격
- 자신의 잔액
- 남은 물건
- 경쟁자의 잔액과 보유 물건
- 앞으로 예상되는 경쟁 강도
- 현재 가설을 유지하거나 포기할 비용

## 4. 전체 카탈로그의 역할

카탈로그는 단순 도감이 아니라 자본 계획판이다.

필수 조건:

- 12개 경매 순서를 모두 사전 공개
- 관심 표시와 메모 제공
- 경매가 끝나도 카드가 같은 위치에 남음
- 물건별 상태와 최종 결과가 누적됨
- 전체 목록을 언제든 다시 볼 수 있음
- 경매 중 카탈로그를 열면 시간 압박을 중지함

카탈로그 정렬을 고정하는 이유는 플레이어가 위치와 순서 자체를 기억 자원으로 사용할 수 있게 하기 위해서다.

## 5. 히든 세트의 역할

히든 세트는 정답을 맞히는 퍼즐이 아니라 자본을 거는 가설이다.

- 세트 이름과 세계관 설명은 시작 시 공개
- 각 세트가 3개 구성이라는 사실도 공개
- 실제 구성품은 비공개
- 2개 보유에도 부분 보상
- 3개 완성에는 더 큰 보상
- 세트에 포함되지 않는 독립 물건도 충분한 단품 가치 가능

플레이어가 경험해야 할 대표 선택:

- 단품으로는 애매하지만 세트 가능성 때문에 구매
- 세트 후보지만 가격이 너무 높아 포기
- 이미 투자한 세트 가설을 중간에 포기
- 경쟁자가 노리는 세트를 피하고 독립 물건으로 전환
- 후반 구성품을 위해 초반의 좋은 물건을 포기

## 6. 공개 호가식 경매의 역할

공개 호가는 단순한 가격 입력보다 다음을 제공한다.

- 경쟁자의 관심을 행동으로 확인
- 다른 참가자의 이탈 시점 관찰
- 현재 가격에서 계속 경쟁할지 반복 결정
- 자신의 과거 투자 때문에 생긴 심리적 집착과 기회비용 경험
- 경쟁자의 잔액 감소를 미래 전략에 반영

공개 호가의 긴장감은 빠른 애니메이션보다 **반복되는 작은 포기 결정**에서 나온다.

## 7. 경쟁자의 역할

경쟁자는 추리 정답을 보여주는 신호가 아니라 가격과 미래 선택권을 압박하는 경제 주체다.

성향은 존재하지만 플레이어에게 공개하지 않는다.

- 세트 추적형: 연결 가능성에 높은 프리미엄
- 개별 가치형: 단품 기대 가치 중심
- 자본 관리형: 후반 선택권 보존
- 비공개 정보 신뢰형: 자신이 낙찰한 물건의 추가 정보 적극 반영
- 공개 정보 중심형: 카탈로그와 시장 결과 중심

플레이어의 목표는 성향 이름을 맞히는 것이 아니다. 어느 경쟁자가 어떤 물건에 돈을 쓰고, 이후 얼마를 남기는지 이해하는 것이다.

## 8. 정보 공개 원칙

### 시작 시

- 중심 사건
- 세트 3개 이름
- 세트별 짧은 설명
- 각 세트 `3개 구성`
- 경매장 배경

### 카탈로그

- 물건 12개
- 순서
- 이미지
- 기본 설명
- 메모와 관심 표시

### 경매 직전

- 해당 물건의 추가 공개 사실

### 경매 종료 후

- 낙찰자
- 최종 가격
- 참가자별 최고 실제 입찰
- 참가자별 잔액
- 플레이어 낙찰 시 소유자 전용 설명

### 게임 종료

- 실제 가치
- 실제 세트 구성
- 세트 보너스
- 점수와 순위
- 모든 경매 기록
- 플레이어 메모

## 9. 최종 결과의 역할

최종 결과는 게임이 플레이어 대신 판단을 평가하는 화면이 아니라, 플레이어가 자신의 판단을 복기하는 자료다.

보여줄 것:

- 순위와 점수 구성
- 실제 물건 가치
- 세트 정답
- 낙찰가와 소유자
- 세트별 소유 분포
- 플레이어 메모
- 플레이어가 얻은 소유자 전용 설명

보여주지 않을 것:

- “이 단서를 놓쳤습니다” 자동 해설
- 메모의 정답·오답 평가
- 봇의 내부 최대 지불 의사
- 봇의 비공개 설명
- 동률 판정이 갈린 정확한 단계

## 10. 실패할 가능성이 높은 설계

### 단서가 장식에 그치는 경우

세계관 문장은 풍부하지만 실제 가치와 세트에 연결되지 않으면 결과가 무작위처럼 느껴진다.

대응:

- 알고리즘이 사실과 단서 키를 먼저 결정
- 생성 모델은 이를 표현
- 변환·검증 계층에서 필수 단서와 충돌 검사

### 세트가 항상 최선인 경우

세트 보너스가 지나치게 크면 단품 판단과 경매 가격 판단이 사라진다.

대응:

- 독립 물건 3개에 충분한 가치 분포
- 부분 보너스와 완성 보너스 플레이테스트
- 세트를 무시한 전략도 승리 가능해야 함

### 공개 호가가 너무 오래 걸리는 경우

최소 인상만 반복하면 12개 경매가 지루해질 수 있다.

대응:

- `+2/+5/+10`
- 현재 최고 입찰자 차례 생략
- 플레이어 이탈 후 봇 연출 생략
- 타이머 15초
- 플레이테스트에서 평균 경매 길이 측정

### 봇이 정답을 아는 것처럼 보이는 경우

봇이 숨은 가치나 세트에 지나치게 정확하면 불공정하게 느껴진다.

대응:

- 봇도 공개·소유자 정보만 사용
- 실제 가치와 세트 정답 접근 금지
- 판단값은 불완전한 정보 기반
- 내부 로그로 정보 접근 검증

### 예비 프리셋이 정상 흐름처럼 사용되는 경우

생성 실패가 자주 발생해도 사용자에게 게임이 시작된다는 이유로 방치될 수 있다.

대응:

- 예비 프리셋 사용을 내부 오류로 기록
- 실패 단계와 원인 저장
- 반복률 모니터링
- 프리셋은 복구 수단으로만 취급

## 11. MVP에서 보호해야 할 경험

다음 경험이 사라지면 제품의 핵심이 훼손된 것으로 본다.

1. 12개 전체를 보고 미리 계획한다.
2. 모든 좋은 물건을 살 수 없다.
3. 경쟁자의 가격 압력 때문에 계획을 바꾼다.
4. 세트 가능성에 돈을 걸지만 확신할 수 없다.
5. 어느 순간 현재 물건보다 미래 기회가 더 중요해진다.
6. 최종 공개에서 자신의 가설을 직접 검증한다.

## 12. 성공 신호

플레이테스트 후 플레이어가 다음과 비슷한 말을 하면 핵심 재미가 작동한 것이다.

- “저 물건을 너무 일찍 비싸게 사서 뒤에서 못 움직였어요.”
- “둘이 같은 세트인 줄 알고 세 번째를 기다렸어요.”
- “경쟁자가 돈을 많이 써서 후반에는 제가 유리할 줄 알았어요.”
- “가치가 높아 보여도 뒤 물건 때문에 포기했어요.”
- “결과를 보니 제가 읽은 단서는 맞았는데 가격 판단을 잘못했네요.”

## 13. MVP 플레이테스트 핵심 질문

1. 플레이어가 시작 전에 실제로 예산 계획을 세우는가?
2. 경매 중 계획이 적어도 한 번 수정되는가?
3. 플레이어가 가격이 아닌 미래 기회비용을 언급하는가?
4. 세트 후보에 자본을 거는 순간이 있는가?
5. 공개 호가가 정보와 긴장을 제공하는가, 단순 대기 시간이 되는가?
6. 봇 행동이 불공정한 정답 접근처럼 느껴지지 않는가?
7. 결과 화면만으로 자신의 판단을 복기할 수 있는가?
8. 한 판 완료 후 다른 시드 또는 같은 시드를 다시 플레이하고 싶은가?
