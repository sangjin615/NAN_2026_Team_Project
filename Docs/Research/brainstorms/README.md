# 브레인스토밍 실행 규칙

1. 기준 명세는 읽기 전용으로 사용한다.
2. 요청서의 후보를 서로 독립적으로 작성한다.
3. 후보 작성이 끝난 뒤에만 기존 baseline을 공개해 비교한다.
4. 비교와 추천은 별도 문서에 기록한다.
5. 추천은 결정이 아니다. 사람의 선택을 결정 문서에 기록한다.
6. 승인된 결정만 후속 명세 변경 또는 구현 작업의 입력이 된다.
