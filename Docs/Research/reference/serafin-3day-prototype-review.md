# 참고 — 세라핀 3일 런 프로토타입 리뷰

- 대상: `prototypes/serafin-3day-run.html` (임시 프로토타입, 화면 구조 승계 안 함)
- 위치 부여: V2 이전 "3단계(짧은 캠페인 + 최종 유물)" 구조의 실험판. V2 기준선 아님.
- 작성일: 2026-07-21

## 무엇이 들어있나

3일 런 완결형: 역할 3종 선택 → 도시 지도 거점 6종(조합·경매장·감정소·상회·술집·거래소) → 의뢰→경매→낙찰품 분류→구매자별 판매→하루 정산 사이클 → 2일차 사건 → 3일차 자격 심사(현금 120G·평판 4)·특별 경매 → 유물 처분 3택 엔딩 → 등급·히스토리.

## 가져갈 것 (메커니즘·교훈, UI 아님)

- **판매 시장 구조**: 구매자별 취향 태그 → 제안가 차등, 매입가 대비 손익 즉시 표시, "지금 팔기 vs 보관" 선택. §7의 핵심이 재미로 작동함을 확인.
- **패스 즉시 정산**: 플레이어 패스 시 남은 봇 경합을 시뮬레이션으로 즉시 해소 — 나쁜 대기 시간 제거 패턴.
- **"이동 무료, 행동만 소비"** 거점 규칙과 하루 동선(route) 개념.
- **감정 전 의뢰 적합성 불확정** — 미감정 제출 = 도박이라는 긴장.
- 시드 재현 + 로컬 히스토리 골격.

## 버릴 것 (V2 불변 조건 충돌)

- 최종 유물 단일 목표 + 현금 게이트(120G): 현금 비축 역설 구조 그대로. → 상회 엔딩 선판정·유물 분리(§2.2)로 대체.
- 의뢰 없으면 경매장 입장 불가, 평판은 의뢰로만: 의뢰 강제. → 의뢰는 수단 중 하나(§2.4).
- 정보상·조사관·사건의 **숨은 태그 직접 공개**: 체크리스트화 장치. → 간접 단서로 재설계.
- 감정 즉시 완전 확정 → 범위 축소형(§6).
- 유물 처분 3택 엔딩 → 상회 성장 판정 엔딩(§11).
- 소액 경제(시작 200G, 가치 10~60) → 자릿수 상승 경제(§9.2).

## 발견된 버그 (재사용 시 주의)

- 2일차 사건 '기록 사본 구매': 현금 12G 미만이면 구매 실패가 아니라 현금이 0이 됨.
- 유지비 정산으로 현금 음수 가능 — 파산 처리 없음.
- 유찰 재경매 없음.

## 판정

거점·판매·하루 사이클이 "한 게임으로 이어지는 감각"을 주는지 확인하는 용도로 소임을 다함. 화면 구조·수치·목표 구조는 승계하지 않는다. M2 설계 시 위 "가져갈 것" 목록만 참조.
