## 문서 방향

제출의 주인공은 Team Loop나 VSL이 아니라 **플레이 가능한 게임과 AI가 만든 플레이 경험의 변화**다.

- 게임 엔진은 가격, 실제 가치, 등급, 보상, 확률과 승패를 판정한다.
- 생성 AI는 설명, 소문, 세트 힌트, NPC 반응과 표시 문구를 만든다.
- VSL은 화면·씬·사운드·플로우의 제작 골격을 제공한다.
- Team Loop와 하네스는 생성 결과 및 게임 회귀를 검증한다.

권장 설명 비중은 게임 50%, AI가 게임 경험에 만든 변화 25%, 제작·검증 효과 15%, 도구 구현 10%다.

## 제출 직전 제거할 것

- 모든 상태 표기
