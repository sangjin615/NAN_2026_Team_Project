## 공통 수정

- 가로 폭에 따라 우측 모서리가 잘리던 버튼 배경을 CSS 배경 확대 방식에서 `border-image` 9-slice 방식으로 변경했다.
- 모든 씬은 1536×1024 비율의 프로젝트 캔버스를 벗어나는 보이는 자식 요소가 없는지 DOM 경계 검사를 수행했다.
- 화면 배경에 이미 그려진 패널 위로 동일한 패널을 다시 덮지 않도록 장면별 live-data 영역을 투명화했다.
- 실패 결과 진입 시 실패 전용 배경 클래스를 실제 Runtime에서 설정하도록 수정했다.
- 완료/실패 상태의 저장 파일을 이어할 때 도시로 잘못 돌아가던 복원 라우팅을 수정하고 실제 재접속으로 결과 화면 복원을 확인했다.
- 이미 8 LOT이 끝난 날 경매 진입을 다시 시도하면 오류 대신 결산으로 돌아가도록 방어 처리했다.

## V6.4 좌표 원본 반영

- `미지의경매장_V6.4_CleanUI_VSL_v1_FINAL.zip`에서 `layout.json`, 화면별 `scene.json`, UI 카탈로그를 확보했다.
- 프로젝트 캔버스를 1536×1024로 변경하고 배경·UI를 함께 contain 변환한다.
- 타이틀의 새 게임·이어하기·전시관·종료·설정과 도시의 술집을 VSL 구조대로 복원했다.
- 술집 배경을 원본 패키지에서 가져오고 정보 구매 기능을 거래소에서 술집으로 이동했다.

## 현재 남은 경계

- API가 생성할 문장이 현재 fixture보다 길면 카드별 줄 수 제한 또는 요약 규칙이 추가로 필요하다.
- 반응형 재배치 대신 VSL 정책대로 전체 3:2 캔버스를 축소하고 레터박스를 보존한다.
- 실제 BGM/SFX 파일과 최종 이벤트 ID는 아직 전달되지 않아 시각 검수와 분리되어 있다.

이 문서의 `통과`는 V6.4 좌표 원본과 현재 데이터 fixture에서 명백한 겹침·잘림·프레임 왜곡이 없다는 의미다. 아직 Runtime에 없는 VSL 기능까지 구현됐다는 의미는 아니다.
