## 공통 수정

- 가로 폭에 따라 우측 모서리가 잘리던 버튼 배경을 CSS 배경 확대 방식에서 `border-image` 9-slice 방식으로 변경했다.
- 모든 씬은 16:9 영역을 벗어나는 보이는 자식 요소가 없는지 DOM 경계 검사를 수행했다.
- 화면 배경에 이미 그려진 패널 위로 동일한 패널을 다시 덮지 않도록 장면별 live-data 영역을 투명화했다.
- 실패 결과 진입 시 실패 전용 배경 클래스를 실제 Runtime에서 설정하도록 수정했다.

## 현재 자료로 더 진행할 수 없는 경계

- 최종 VSL layout JSON의 실제 x/y/width/height가 없으므로 현재 좌표는 제공된 1600×900 목업 픽셀을 비율로 옮긴 값이다.
- API가 생성할 문장이 현재 fixture보다 길면 카드별 줄 수 제한 또는 요약 규칙이 추가로 필요하다.
- 16:9 이외의 화면은 레터박스로 보존한다. 별도의 4:3·모바일 재배치는 범위에 포함하지 않았다.
- 실제 BGM/SFX 파일과 최종 이벤트 ID는 아직 전달되지 않아 시각 검수와 분리되어 있다.

이 문서의 `통과`는 제공된 목업과 현재 데이터 fixture에서 명백한 겹침·잘림·프레임 왜곡이 없다는 의미이며, 최종 VSL 좌표 원본과의 픽셀 동일성을 의미하지 않는다.
