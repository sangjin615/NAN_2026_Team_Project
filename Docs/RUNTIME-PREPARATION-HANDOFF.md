# 미지의 경매장 런타임 준비·인수인계

## 현재 준비된 것

- 12일 × 8 LOT의 고정 런과 2일 선행 생성 버퍼
- 도시에서 의뢰소·경매장·거래소·상회·조합·유물 전시관으로 이동
- 물품별/선택 감정과 판매, 정보 구매
- 봇 입찰, 시세, 세트, 의뢰, 상점, 대출, 마감, 파산, 유물 메타 진행
- 로컬 저장과 JSON 플레이 기록 다운로드
- 생성 API 요청·응답 JSON Schema
- VSL 매핑 템플릿

## VSL ZIP 수령 즉시 할 일

1. 씬 ID와 기준 해상도를 `Runtime/contracts/vsl-map.template.json`에 입력한다.
2. 버튼·텍스트·이미지 요소 ID와 bounds를 입력한다.
3. `MockVslAdapter`를 실제 VSL 어댑터로 교체한다.
4. 장소 이동, 팝업, 사운드 이벤트를 매핑한다.
5. 1920×1080과 목표 실행 해상도에서 시각 QA를 수행한다.

## API 수령 즉시 할 일

1. 요청과 응답이 `Runtime/contracts`의 스키마를 만족하는지 검사한다.
2. 런 시작 시 1~3일차를 생성하고, 매일 다음 2일을 보충한다.
3. 제한 시간 초과·잘못된 JSON·누락 LOT은 로컬 폴백으로 대체한다.
4. API/폴백 여부와 지연 시간을 플레이 이벤트 로그에 기록한다.

## 완료 정의

- 같은 시드가 같은 96 LOT·시세·세트 관계를 만든다.
- 모든 장소에서 현금·인벤토리·의뢰·대출 상태가 보존된다.
- API가 없어도 12일 진행이 중단되지 않는다.
- 실행 로그만으로 결과와 주요 행동을 재현할 수 있다.
