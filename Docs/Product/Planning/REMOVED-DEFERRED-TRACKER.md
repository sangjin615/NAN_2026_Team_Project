# 삭제·보류·미완료 추적표

작업 중 기능을 제거하거나 완성하지 못했을 때 이유와 재개 조건을 남긴다. 상태는 `삭제`, `보류`, `외부 입력 필요`, `대체 구현`, `해결`로 관리한다.

화면 비율·에셋·글자·정렬 문제는 `UI-CONSISTENCY-ISSUES.md`에서 별도로 관리한다.

## 기록 규칙

- 기능이나 화면을 빼면 같은 커밋에서 이 표에 이유를 추가한다.
- 임시 대체는 최종 구현처럼 표기하지 않고 `대체 구현`으로 남긴다.
- 외부 에셋·결정·인증이 필요한 항목은 필요한 입력을 구체적으로 적는다.
- 문제가 해결되더라도 행을 지우지 않고 상태를 `해결`로 변경해 이력을 보존한다.
