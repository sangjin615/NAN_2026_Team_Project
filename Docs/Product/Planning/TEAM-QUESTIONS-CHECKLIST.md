# 팀 확인 질문

아래 항목의 답만 채우면 된다. 미응답 시 괄호 안 기본값으로 구현한다.

## 게임 규칙

- [ ] 최종 성공 조건: 100,000G / 12일 생존 / 둘 다? (`100,000G + 12일 생존`)
- [ ] 마감 실패 시 즉시 종료인가? (`즉시 종료`)
- [ ] 경매는 반복 호가 방식인가, 한 번 제출 방식인가? (`반복 호가`)
- [ ] 감정 전 판매를 허용하는가? (`허용`)
- [ ] 세트는 자동 최적 조합인가, 플레이어 선택인가? (`판매할 물품 중 자동 최적`)
- [ ] 하루 중 장소 이동 횟수 제한이 있는가? (`없음`)

## VSL

- [ ] 기준 해상도
- [ ] 전체 씬 ID 목록
- [ ] 요소별 ID·좌표·크기
- [ ] 팝업 목록과 닫기 규칙
- [ ] 화면 전환 이름과 길이
- [ ] SFX/BGM 파일명과 재생 조건
- [ ] 값 주입·이벤트 수신 인터페이스

## 생성 API

- [ ] 호출 URL과 인증 방식
- [ ] 모델과 요청 제한
- [ ] 제한 시간과 재시도 정책
- [ ] JSON Schema 버전
- [ ] 결과 저장 및 재사용 여부
- [ ] 부적절하거나 스키마 밖 응답 처리 방식
