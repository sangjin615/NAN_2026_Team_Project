## 결론

스킬의 확인된 효과는 **입력 컨텍스트 절감과 계약 준수율 개선**이다. 현재 표본만으로 속도가 빨라졌다고 말할 수는 없다. 하네스의 효과는 잘못된 결과가 게임으로 들어오는 것을 차단하는 것이다. 실제 지연 단축은 다음 최적화가 필요하다.

1. 오늘 필요한 세트만 전달한다.
2. 출력 필드 수 또는 문장 길이를 줄인다.
3. 모델이 만든 ID를 신뢰하지 않고 입력 ID를 위치 기반으로 복원한다.
4. 1~3일차를 선행 생성해 지연을 플레이 뒤로 숨긴다.
5. 모델별로 최소 10회 측정해 재시도율과 중앙값을 비교한다.

이 과정에서 두 가지 Team Loop 호환 문제도 재현했다.

1. Windows에서 `shell:false`로 `npm.cmd`를 실행하면 `spawn EINVAL`이 발생했다. 하네스는
   `cmd.exe /d /s /c "npm test"`로 교체했다.
2. CLI의 `reviewer run`이 서버가 요구하는 `reviewSessionPid`를 보내지 않았다. CLI 요청에
   `process.pid`를 전달하도록 수정했다.
