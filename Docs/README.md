# 문서 안내

이 폴더는 문서의 역할에 따라 다음과 같이 나눈다.

- `Product/` — 제품 기획, 작업 계획, UI 이슈, 원본 기획서
- `Development/` — 런타임과 생성 시스템 구현·인계 자료
- `Deployment/` — 독립 실행본과 Pages 배포 안내
- `Audio/` — 사운드 출처와 크레딧
- `Verification/` — 측정 계획, 검증 결과, 해커톤 증거
- `Submission/` — NAN 2026 제출 초안과 최종 문서
- `Research/` — 브레인스토밍, 의사결정 기록, 참고 자료
- `Archive/` — 과거 검토본과 임시 파일

아래 세 문서는 공동 작업 규칙과 코드에서 직접 참조하므로 루트에 유지한다.

- `PARALLEL-SESSION-NOTES.md`
- `GENERATION-VERIFICATION-HANDOFF.md`
- `GENERATION-ROUTER-PARITY.md`

게임 구현의 현재 기준은 `../Runtime/`이며, 이 폴더의 과거 문서보다 런타임 코드와
검증 결과를 우선한다.
