# 제출용 핵심 요약 초안

## 3문장 버전

8일 동안 미지의 경매장은 정적 기획서와 화면 이미지 중심 상태에서, 12일×8 LOT의 경매 일정을 실행하고 감정·판매·퀘스트·대출·결산을 연결하는 플레이 가능한 런타임 프로토타입으로 발전했다. View Spec Lite는 목업의 씬·좌표·사운드·9-Slice 정보를 사람이 수정 가능한 ZIP/JSON으로 전달했고, Codex와 Team Loop는 이를 런타임·생성 계약·자동 검증으로 연결했다. 900개 시드에서 86,400 LOT의 일정 오류가 0건이었고 자동 테스트 12/12를 통과했으며, 로컬 생성 실험에서는 스킬/하네스가 입력 문자를 59.3% 줄이고 엄격 JSON 계약 통과를 소표본 기준 0/2에서 3/3으로 개선했다.

## 제출서 본문용

### 문제

게임 기획, UI 목업, 밸런싱 문서, 품목 이미지와 사운드는 존재했지만 서로 다른 형식으로 흩어져 있었다. 화면을 실제로 이동하고 하루를 진행하며 경제 규칙과 AI 생성 콘텐츠를 함께 검증할 수 있는 프로젝트는 없었다.

### 접근

사람이 만든 결과물을 출발점으로 삼았다. VSL은 목업의 씬·좌표·크기·사운드·흐름을 편집 가능한 JSON/ZIP으로 만들고, 게임 엔진은 기준가·실제 가치·경제 규칙을 소유한다. AI는 설명·루머·세트 관계·NPC 반응을 생성하며, Team Loop 하네스가 JSON 계약과 게임 테스트를 통과한 결과만 프로젝트에 전달한다.

### 프로젝트 변화

- 12일×8 LOT, 총 96 LOT의 재현 가능한 런 구조 구현
- 60개 기본 품목과 240개 등급 이미지 카탈로그화
- 16개 장소 배경과 VSL 씬 구조 연결
- 감정·경매·인벤토리·판매·퀘스트·대출·결산 상태 연결
- 현재일+2일 선행 생성 버퍼와 API 실패 폴백 구현
- VSL export의 구현 메타데이터 손실을 발견하고 편집기·복구 도구 수정
- 편집 가능한 최신 VSL 프로젝트를 Git LFS로 팀에 배포

### 검증 결과

- 900개 시드, 86,400 LOT 생성
- 잘못된 12일 일정 0건
- 목표 등급 분포와 최대 차이 0.19%p
- 자동 테스트 12/12 통과
- 로컬 모델의 2단계 생성 실제 성공
- 스킬/하네스 적용 시 입력 문자 59.3% 감소
- 엄격 계약 통과: 장문 0/2 → 스킬 3/3(소표본)

### 정직한 한계

현재 결과는 전체 게임 완성이 아니라 핵심 플레이와 콘텐츠 생성 파이프라인을 검증한 프로토타입이다. VSL의 수동 UI 제작시간 절감률과 외부 API의 비용·P95 지연 시간은 아직 측정하지 않았다. 또한 스킬/하네스가 계약 준수에는 도움을 줬지만 로컬 생성 속도를 개선했다는 근거는 없다.

## 발표용 한 줄

**AI가 목업을 대신 그린 것이 아니라, 팀의 문서·목업·밸런싱 결과를 실행하고 실패를 검증할 수 있는 게임 제작 파이프라인으로 연결했다.**
