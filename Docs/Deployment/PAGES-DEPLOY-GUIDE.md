# GitHub Pages 배포 — 저장소 소유자용 안내

**해야 할 일: 설정 화면에서 브랜치 하나를 고르고 저장하는 것뿐이다.** 코드는
이미 준비되어 있다. 5분이면 끝나고, 끝나면 심사자가 클릭 한 번으로 게임을
여는 공개 주소가 생긴다.

- 대상 저장소: `sangjin615/NAN_2026_Team_Project`
- 필요한 권한: 저장소 **Settings** 에 들어갈 수 있는 소유자 또는 관리자
- 이 작업이 필요한 이유: 제출 요강 1번이 "링크 클릭만으로 실행되는 웹 빌드 배포"를
  요구한다. 공개 주소가 없으면 다른 것이 다 갖춰져도 심사 대상에서 빠질 수 있다

## 1. 설정 화면에서 켠다

아래 주소를 연다.

```
https://github.com/sangjin615/NAN_2026_Team_Project/settings/pages
```

**Build and deployment** 항목에서 이렇게 고른다.

| 항목 | 고를 값 |
|---|---|
| Source | **Deploy from a branch** |
| Branch | **`codex/vsl-runtime-core`** |
| Folder | **`/ (root)`** |

고른 뒤 **Save** 를 누른다.

### 왜 `main` 이 아닌가

**`main` 은 게임이 거의 없는 상태다.** 확인한 시점 기준으로 작업 브랜치보다
387커밋 뒤처져 있고, 마지막 커밋이 "공용 작업 규칙 문서 추가"다. `main` 으로
배포하면 심사자가 빈 페이지나 옛 버전을 보게 된다.

게임 본체는 `codex/vsl-runtime-core` 에 있다. 마감 전에 브랜치를 병합하려면
충돌을 풀 시간이 필요하므로, **지금은 게임이 있는 브랜치를 그대로 배포하는
편이 안전하다.** 병합은 마감 뒤에 해도 된다.

## 2. 빌드를 기다린다

Save 를 누르면 자동으로 배포가 돈다. 보통 1~3분이다.

- 진행 상황: 저장소 상단 **Actions** 탭
- 완료되면 같은 설정 화면 위쪽에 주소가 표시된다

주소는 이렇게 나온다.

```
https://sangjin615.github.io/NAN_2026_Team_Project/
```

저장소 루트에 넘김 페이지를 넣어 두었으므로 이 주소가 곧바로 게임으로 이동한다.
`.../Runtime/` 을 따로 붙일 필요가 없다.

## 3. 켠 뒤 반드시 확인할 것

제출 요강이 **"시크릿 모드 또는 로그아웃 상태에서 접근 확인"** 을 요구한다.
로그인한 브라우저에서만 열리면 심사자는 못 연다.

1. **시크릿 창**(Chrome: `Ctrl+Shift+N`)을 연다
2. 위 주소를 붙여 넣는다
3. 타이틀 화면이 뜨는지 본다
4. **새 게임 → 슬롯 선택 → 새 여정 시작** 까지 눌러 도시 화면이 나오는지 본다

여기까지 되면 배포는 끝이다.

## 4. 안 될 때

| 증상 | 원인과 조치 |
|---|---|
| 주소가 404 | 아직 빌드 중이다. Actions 탭에서 완료를 기다린다. 5분이 지나도 그대로면 Branch 를 다시 확인한다 |
| 화면은 뜨는데 그림이 없다 | 배포에 에셋이 빠진 경우다. Folder 가 `/ (root)` 인지 확인한다 |
| 흰 화면만 나온다 | 브라우저에서 `F12` → Console 탭의 빨간 오류 메시지를 그대로 알려주면 원인을 찾을 수 있다 |
| 게임은 되는데 물품 설명이 밋밋하다 | 생성 API 가 일시적으로 응답하지 않은 경우다. 게임은 정상 진행되며 다시 시작하면 대개 복구된다 |

## 5. 이 주소로 무엇을 하는가

배포가 끝나면 주소를 팀에 알려 준다. 제출 문서 두 곳에 들어간다.

- `Docs/Submission/NAN-2026-SUBMISSION-FINAL/01-게임소개및설명.md` 의 "플레이 URL" 칸
- 실제 플레이 영상 설명란

## 참고 — 미리 해 둔 것

소유자가 따로 할 일은 없다. 확인용으로만 적는다.

- **루트 넘김 페이지**(`index.html`) — 주소를 짧게 유지한다
- **`.nojekyll`** — GitHub Pages 가 밑줄로 시작하는 폴더를 건너뛰는 기본 동작을
  끈다. 실제로 `Runtime/tools/__pycache__` 가 여기에 해당한다
- **게임은 설치·로그인·서버가 필요 없다.** 정적 파일만으로 돈다
- **생성 API 는 이미 공개 엔드포인트로 붙어 있다.** 어떤 주소에서 열어도
  동작하도록 CORS 를 열어 두었고, 응답하지 않을 때는 미리 준비된 문구로 진행이
  이어진다
