## 해석 원칙

- “AI가 게임을 완성했다”가 아니라 “문서·목업 상태를 실행·검증 가능한 프로젝트로 이동시켰다”고 쓴다.
- 실험 표본이 작은 결과에는 반드시 `소표본`을 붙인다.
- Git의 추가 줄 수는 바이너리 파일을 설명하지 못하므로 생산성의 단독 지표로 쓰지 않는다.
- ChatGPT/Codex 대화는 과정 증거이며, 최종 효과는 Git·테스트·JSON·실행 화면으로 증명한다.
