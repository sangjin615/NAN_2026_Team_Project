# 미지의 경매장 프로젝트 효과 측정

## 결론

이번 AI 협업의 가장 큰 효과는 도구 제작 자체가 아니다. 미지의 경매장이 **설명 가능한 기획물**에서 **실행·교체·검증 가능한 게임 프로토타입**으로 바뀐 것이다.

## 무엇이 실제로 나아졌나

| 이전 상태 | 현재 상태 | 프로젝트 효과 |
|---|---|---|
| 12일·8 LOT 규칙이 문서에 존재 | 시드 기반 96 LOT 일정 생성 | 같은 조건 재현 가능 |
| 화면 목업이 개별 이미지 | 16개 배경과 VSL 레이아웃 연결 | 장면 단위 구현 가능 |
| 경매·경제 규칙이 분산 | 감정·구매·판매·퀘스트·대출·결산이 상태 공유 | 하루 플레이 루프 검증 가능 |
| 생성 API 역할이 불명확 | 엔진 수치와 AI 문장을 JSON 계약으로 분리 | 모델 교체 시 규칙 보존 |
| API 실패 시 진행 방식 없음 | 2일 버퍼와 결정론적 폴백 | 생성 실패가 게임 중단으로 이어지지 않음 |
| 수치 안정성 근거 부족 | 900시드·86,400 LOT 검증 | 일정·등급 분포 근거 확보 |
| 사람이 눈으로만 확인 | 8개 자동 테스트 | 수정 후 회귀 확인 가능 |

## AI가 한 일과 사람이 한 일

### 사람이 제공한 것

- 게임 기획, 12일×8 LOT 방향, 공개 경매 원칙
- 기준가·실제 가치는 엔진, 설명·세트 관계는 AI가 맡는다는 소유권 결정
- UI 목업, 배경, SFX/BGM, 품목 스프라이트, 밸런싱 문서
- VSL에서 직접 이어하기 좌표 수정 및 시각 판단

### AI 협업으로 전환한 것

- 문서 규칙을 런타임 모듈과 JSON 계약으로 변환
- 품목·화면 자산을 카탈로그와 씬 구조로 연결
- API/로컬 모델 실패를 고려한 버퍼·재시도·폴백 설계
- 대량 시드 측정과 자동 회귀 테스트
- VSL export 오류 탐지·복구 및 편집 가능한 최신 패키지 제작
- 해커톤용 주장과 원본 증거 연결

## 아직 수치화하지 못한 효과

- 플레이테스터 만족도와 완주율
