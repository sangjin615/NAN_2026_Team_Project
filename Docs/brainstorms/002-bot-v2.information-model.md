## 1. 기본 원칙 (이 세션에서 합의된 것)

1. **압력 함수 원칙**: 유저와 봇은 같은 게임을 하지 않는다(유저: 상회 성장·감정·판매 / 봇: 경매층만). 따라서 봇은 상인 시뮬레이션이 아니라 **일관된 겉모습을 가진 압력 함수**다. 봇의 무대 밖 삶(환금·의뢰·사정)은 전부 허구(표현)로 처리하고, 엔진에는 행동 일관성에 필요한 최소 상태(지갑 등)만 둔다.
2. **정보 대칭 원칙 (경매장 바닥 한정)**: **봇의 입력 집합 ⊆ 유저의 가시 집합.** 봇이 판정에 읽는 모든 정보는 유저도 볼 수 있어야 한다. 역은 성립하지 않는다 — 감정 결과·술집 정보는 유저 독점 우위. 대칭의 적용 범위는 경매장 공개 정보에 한하며, 봇의 오프스크린 상태(지갑 보충 등)에는 적용하지 않는다. 유일한 예외는 숙적의 노이즈 축소(§5.3)이며, 공표되므로 허용된다.
3. **접대의 정의**: 접대 = 약하게가 아니라 **읽을 수 있게**. 봇은 규칙적이고, 읽는 자는 유저다. 봇의 강함은 심리가 아니라 돈(지갑·마진)에서 나온다. 하한선: 무경합 낙찰은 승리감이 아니라 역선택 공포를 주므로, **최소 경합 보장**이 접대의 조건이다.
4. **plan 원칙의 재정식화**: "경매 중 재계산 금지"를 "plan은 **값**을 고정한다"에서 "plan은 **정책(조건부 규칙표)**을 고정한다"로 바꾼다. 경매 중 새로운 가치 판단은 여전히 금지. plan 시점에 미리 적힌 if-then은 허용(시드 재현성 유지).

## 3. 봇 입력 인벤토리 — step 시점 (원칙 위반 강도별)

§1.4 재정식화 기준. plan에 정책으로 고정된 조건부 규칙만 step에서 실행된다.

### Tier 0 — 무위반 (현행 허용)

현재가, 최소 인상폭, 자기 plan 값, 자기 잔여 예산.

### Tier 1 — 정책 고정이면 위반 아님 (허용 제안)

| 변수 | 살 수 있는 행동 |
|---|---|
| 호가 라운드 수 | "N라운드 넘게 끌리면 점프로 끝내러 감" — 성격 표현 |
| 현재가 / est_bot 비율 | 구간별 점프 폭 차등 (여유 구간 큰 점프, 상한 근처 잔걸음) |
| 잔존 경쟁자 수 | "1:1이 되면 물러서는/무는" 브랜치 차별화 |

### Tier 2 — 상대 식별 반응 (부분 위반, 조건부 허용 제안)

| 변수 | 판정 |
|---|---|
| 현재 리드가 누구인지 | **숙적(§5.3)에게만 허용**: plan에 "리드=대상이면 지속 의지 +δ" 고정. 일반 봇 전면 허용 시 고무줄 난이도 인상. 봇 간 라이벌("숙명의 상대" 동기 원형)은 안전한 사용처 |
| 플레이어의 행동 시간(망설임) | **금지** — 체감이 "읽혔다"가 아니라 "랜덤하게 당했다"가 됨. 숙고의 벌점화(접근성 문제) |

### Tier 3 — 가치 재추정 (진짜 위반, 금지 유지)

| 변수 | 판정 |
|---|---|
| 타인 입찰 강도에서 가치 역추정 (herding) | **금지** — ① 봇 과열이 실가치 신호를 증폭(누설 금지와 정면 충돌) ② "봇 따라 사기"가 안목을 대체 ③ E02 검증 불가능한 연쇄 동학. 유일한 반론인 "호가 낚시 재미"는 방향을 뒤집어 보존한다: 봇이 유저를 읽는 게 아니라 **유저가 봇을 읽는** 게임으로 |

근거(심리전 vs 접대 판단): 심리전의 재미는 상호 가시성을 요구한다. 봇의 내심은 보이지 않으므로 봇이 유저를 읽어도 유저 체감은 불운일 뿐이다. 이 게임의 1층 재미는 "싸게 살 수 있을까"이지 수싸움이 아니며, 긴장은 경제 압력이 담당한다.

## 4. 유저 정보 인벤토리

### 4.1 카탈로그 (경매 전, §5 계승)

| 정보 | 상태 |
|---|---|
| 물건 이름·설명·출처 텍스트 (AI 생성) | 확정 |
| 공시 추정 범위 | 확정 (§6). **미정: 범위가 항상 참인가**(실가치 포함 보장?) — 감정의 의미를 좌우 |
| 계열·강조 키워드 | 확정 계승 |
| 소유자 전용 정보 (내 보유물의 추가 정보) | 확정 계승 (§5) |
| 유찰·재경매 표시 | 확정 계승 |

### 4.2 감정 (유저 독점 우위, §6)

범위 축소, 리스크 태그 발견, 전문성 성장으로 정확도 향상. **봇은 감정소를 쓰지 못한다** — 유저 우위의 제1원천.

### 4.3 시장

시장 변동 사건(§10), 거래소의 구매자별 제안가(사후적 가치 피드백), 술집 소문(§4 — **MVP 제외**, §15). **미정: 유저가 참가하지 않은 세션의 낙찰 결과 공개 여부** — C2 봇이 읽는 이력을 유저가 못 보면 대칭 원칙 위반.

### 4.4 경쟁자

동기 텍스트(런 시작 생성), 행동 관찰(호가·점프·이탈 라인 — **유저의 최대 정보원**), 봇 잔액·낙찰 이력. **미정: 잔액·보유물의 UI 노출 방식** — 004는 §10.2 공개 정보로 취급했으므로 V2도 공개가 기본값, 표시 수준만 결정.

### 4.5 은폐 (설계상 절대 비공개)

실가치, 감정 전 숨은 태그, 봇의 est_bot·maxPay·뿌리 라벨, 미래 출품.

## 5. 유저 사고 모델 (경매 한 판의 내적 독백)

### 5.1 국면별

| 국면 | 유저의 생각 | 설계 함의 |
|---|---|---|
| 카탈로그 | "뭐가 돈이 되지?" — 공시 범위 vs 설명 대조로 저평가 탐색. **출구 사고**: "사면 누구한테 팔지? 묶음이 되나? 의뢰에 쓰나?" | 출구 사고는 V2 신규 회로 — V1 분석으로 안 잡힘 |
| 경매 중 | "쟤 왜 저래?" — 봇 행동에서 정보 역추정. 무경합이면 **역선택 공포**("왜 아무도 안 받지"). 상한 근처에서 자기 절제 싸움 | "쟤 왜 저래?"에 두 개의 그럴듯한 답(동기 vs 가치)이 항상 공존해야 함 — 봇 설계의 성공 기준 |
| 직후 | 이겨도 기쁨 유예("잘 산 건가"), 지면 프로파일 갱신("쟤 이탈 라인이 저기구나") | 승리감 = 낙찰 순간이 아니라 "내 읽기가 맞았다"의 **지연된 확인**(감정→판매에서 회수) |
| 세션 간 | 봇 프로파일링, 시장 추세 읽기, 자금 계획 | "3~4판 뿌리 구분" 가설이 노리는 층 — 단골(§6.1)에만 적용 |

### 5.2 유저가 하고 싶은 것 — 가치는 경로의 함수

"유저가 느끼는 가치 ≠ 실제 가치"에는 두 현상이 섞여 있다: ① 추정 오차(감정·노이즈로 기존 모델링) ② **경로 가치** — 같은 물건이 출구에 따라 다른 가치를 가짐:

| 경로 | 유저에게의 가치 | 성격 (제안: 리스크-수익 사다리) |
|---|---|---|
| 의뢰 납품 | 계약가 (실가치 무관 고정) | 저분산·확정·조건 제약·**상한 낮음** (§8 일치) |
| 자유 판매 | 실가치 × 구매자 취향 계수 | 중분산·상시 기본 경로 |
| 세트 일괄 | 실가치 + 계열 프리미엄 지분 | 고분산·자본 잠김·**상한 최고** (§7 일치) |

- 프로토타입에서 의뢰가 지배한 원인: 저위험 + 고수익 + (세라핀판) 강제 — 셋을 다 가진 경로는 반드시 지배한다.
- 평판은 "추가 돈"이 아니라 **각 경로의 계수**(의뢰 계약가 배수 / 상위 구매자 해금 / 일괄 프리미엄 배수)로 — 지배 경로 방지.
- **봇에의 영향 (이 세션 범위)**: 봇 maxPay는 est 기반, 유저 지불 의사는 경로 기반. 의뢰가 실가치의 수 배를 주면 유저는 est를 넘겨 부르고 봇은 무저항 — 의뢰 대상 물건의 경매 긴장 붕괴. 대응 후보: "납기가 급한 상인" 동기 원형(특정 태그 est 초과 지불 + 기한 임박 과열 — 진짜 의뢰 시스템이 아니라 파라미터, §1.1 압력 함수 원칙).
- 사다리 수치 자체는 봇 세션 범위 밖 — 경제 트랙 이관(§7).

## 6. 캐스트 구조 (recommendation의 "런 캐스트" 갱신)

### 6.1 2층 구조: 단골 + 뜨내기

유저와 봇은 같은 상황에 있지 않고, 모든 경매에 같은 얼굴이 나올 필요도 없다.

- **단골**: 런 캐스트 핵심 3~4인(임시). 프로파일링 대상 — "3~4판 뿌리 구분" 가설의 적용 범위.
- **뜨내기**: 세션마다 뽑히는 1회성 경쟁자. 같은 트리에서 생성되나 축적 관찰 불가 — 단골을 다 읽은 뒤에도 "저 처음 보는 자는 뭐지"를 유지하는 **역선택 공포 보존 장치**.
- 좌석(임시): 3석 = 단골 2 + 뜨내기 1. **비율이 곧 학습 재미 vs 불확실성의 밸런싱 노브** — E02·플레이테스트 대상.
- 세션별 편성: 경매의 격·계열에 따라 캐스트가 달라짐(고가 세션 큰손, 저가 세션 전매상, 사건성 비밀 경매 테마 캐스트). "이 경매엔 누가 올까"가 카탈로그 읽기의 일부가 된다.

### 6.2 숙적 (조건부 등장 제안)

접대 구도 안의 "진짜 강한 하나". 강함의 레버는 유저 읽기가 아니라:

1. **정보 폭**: 일반 봇은 자기 뿌리의 소스만, 숙적은 시장 이력 + 타인 잔액 + 보유 겹침 전부.
2. **노이즈 축소**: ±30% → ±15%(임시). 004가 "은밀한 우열"로 기각한 레버 — 기각 사유가 은밀함이므로 **공표하면 해소**(술집 소문·동기 텍스트가 "이 도시의 큰손"으로 예고).
3. **지갑**: 캐스트 최대.
4. Tier 2 리드 식별 허용(유일): "리드=플레이어면 지속 의지 +δ" — 예고된 한 명이 무는 것은 고무줄이 아니라 서사.

등장은 조건부(상회 단계 2부터 — 임시)로: 첫 런부터 벽이 있으면 접대가 아니게 됨. §13 도전과제 "특정 경쟁자 3연승"의 판정측 짝.
