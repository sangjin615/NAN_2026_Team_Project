# 에셋·UI 미확정 항목

> 2026-08-03 결정 반영: 감정은 의뢰소의 `정밀 감정` 업무로 통합했다. 거래소는 시세 확인과 판매만 담당한다.

팀 이미지와 현재 런타임을 연결하면서 확인한 빈 항목이다. 배치만으로 해결되는 문제와 규칙 결정이 필요한 문제를 구분한다.

## 바로 사용할 수 있는 에셋

- 17개 업스케일 씬 배경: `Runtime/assets/scene-backgrounds`
- 60종 × 4등급 경매품 이미지: `Runtime/assets/items`
- 런타임에 연결한 유물 이미지 9종: `Runtime/assets/relics`
- 기본·호버·눌림·비활성 버튼 스킨과 패널 9-slice: `Runtime/assets/ui/skin-v1`
- 화면 배치 기준이 되는 1600×900 목업 15장: `ui_1600x900_v2`

## 에셋이 비어 있는 부분

1. 술집 정보상 NPC의 개별 투명 배경 초상화가 없다. 최신 술집 목업에는 인물이 합쳐져 있어 배경 참고용으로만 사용할 수 있다.
2. 도시와 장소 HUD에서 사용하는 달력·자산·보관칸·상회·대출 아이콘의 동일 화풍 개별 파일이 모두 갖춰져 있지 않다.
3. 잠긴 유물용 공통 실루엣과 자물쇠의 독립 에셋이 없다. 현재는 CSS 단색 실루엣으로 대체한다.
4. `ui_1600x900_v2`는 글자와 예시 금액이 박힌 완성 목업이다. 동적 런타임 배경으로 직접 쓰려면 글자를 제거한 clean 버전이 필요하다.

## 버튼을 만들기 전에 규칙 결정이 필요한 부분

### 술집

- 목업은 정보상 4명 구조지만 현재 규칙은 `수요 동향`, `출품 목록`, `경쟁자 정보` 3종만 유효하다.
- 네 번째 `출품 순서`는 밸런싱 문서에서 가치가 없어 보류된 상태다.
- 현재 런타임은 확정된 3종만 표시한다.

### 거래소

- 거래소는 시세 확인과 판매만 담당한다.
- `세트 예약 관리`는 게임 범위에서 제거한다.

### 의뢰소·감정 — 구현 완료

- 보유 물품별 이미지, 등급, 계열, 감정 비용을 의뢰소 카드에 표시한다.
- 감정 완료 후 실제 가치와 오차 범위를 같은 카드에 표시한다.
- 담보 물품과 비용 부족 상태는 버튼을 비활성화한다.
- 거래소에서는 감정 버튼을 제거하고 시세 확인과 판매만 제공한다.

### 상회

- 상회는 승급과 보관칸 확장만 담당한다.
- 판매 기능은 거래소에만 둔다.

### 조합

- 담보 물품 선택 UI와 대출액·만기 상환액 미리보기는 구현 완료했다.
- 현재 확정 규칙대로 선택 물품 정산가치의 35%를 대출하며 동시 대출은 1건이다.
- 대출액은 밸런싱 계약대로 선택 담보 정산가치의 35%로 고정한다.

## 현재 대체 구현

- 동적 수치가 필요한 화면은 clean 업스케일 배경 위에 HTML UI를 올린다.
- 기능 규칙이 없는 버튼은 시각적으로만 추가하지 않는다.
- 누락 아이콘은 텍스트 HUD로 유지한다.
- 세부 규칙이 정해지면 이 문서의 항목을 기준으로 기능과 에셋을 동시에 연결한다.
