# 캡처·영상·에셋 자료 수집 계획

## 1. 게임 설명 PDF용 화면

| 번호 | 필요한 화면 | 보여줘야 하는 내용 | 현재 상태 |
|---|---|---|---|
| G1 | 메인 또는 도시 | 게임 제목과 분위기 | 현재 런타임 캡처 가능, 최종본은 VSL 적용 후 교체 |
| G2 | 경매 | 물건, 현재가, 경쟁자, 입찰 행동 | 현재 런타임 캡처 가능 |
| G3 | 거래소/감정 | 매입가, 미감정 상태, 감정 후 실제가치 범위 | 현재 런타임 캡처 가능 |
| G4 | 판매/의뢰 | 보유품 판매와 의뢰 비용·보상 판단 | 현재 런타임 캡처 가능 |
| G5 | 결산 또는 엔딩 | 8 LOT 결산, 2일 생성 버퍼, 12일 결과 | 현재 런타임 캡처 가능 |

화면은 기능이 많이 보이는 것보다 글자가 읽히고 핵심 판단이 한눈에 보이는 장면을 선택한다.

## 2. AI 기술 PDF용 그림

| 번호 | 필요한 자료 | 구성 |
|---|---|---|
| A1 | 역할 분리 표 | 엔진 수치 vs AI 표현 |
| A2 | 2단계 생성 흐름 | 런 시작 → 일일 생성 → 검증 → 폴백 |
| A3 | 실제 입출력 예시 | 엔진 LOT 입력과 생성 설명 일부 |
| A4 | 검증 실패·교정 예시 | 잘못된 ID → 재시도 → 통과 |
| A5 | 정량 결과 표 | 59.3%, 38.5%, 0/2→3/3, 4/4, 8/8 |
| A6 | 게임 적용 화면 | 생성된 설명이 실제 LOT 화면에 표시된 장면 |

## 3. 30~60초 실제 플레이 영상 초안

권장 길이: 45초

| 구간 | 화면 | 전달 내용 |
|---:|---|---|
| 0~4초 | 제목/도시 | 미지의 경매장 정체성 |
| 4~12초 | 오늘의 LOT와 단서 | 무엇을 추론하는 게임인지 |
| 12~24초 | 경쟁 입찰 | 핵심 긴장과 조작 |
| 24~32초 | 감정 | 비용을 내고 정보를 얻는 판단 |
| 32~40초 | 판매/의뢰 | 낙찰 후 경제 루프 |
| 40~45초 | 결산/다음 날 | 12일 성장 구조 |

`[추가 권장]` 영상 자막은 기술 설명보다 플레이 판단을 짧게 쓴다.

- “설명과 소문으로 실제 가치를 추론”
- “정보를 살 것인가, 위험을 감수할 것인가”
- “12일 동안 상회를 성장시켜 최종 경매로”
