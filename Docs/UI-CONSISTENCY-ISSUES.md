# UI 일관성 문제 추적

기능 삭제·보류는 `REMOVED-DEFERRED-TRACKER.md`에서 관리하고, 이 문서는 화면 비율·에셋·글자·레이아웃 품질 문제를 유형별로 누적한다.

## 판정 기준

| 심각도 | 기준 |
|---|---|
| P0 | 진행 불가, 버튼 조작 불가, 주요 정보가 보이지 않음 |
| P1 | 다른 기능으로 오인하거나 잘못된 값·문구를 표시함 |
| P2 | 비율 왜곡, 겹침, 글자 가독성처럼 완성도를 크게 떨어뜨림 |
| P3 | 미세한 정렬·여백·색상 차이 |

## 새 화면을 받을 때 확인할 항목

1. 화면 해상도와 브라우저 확대 비율을 같이 기록한다.
2. 버튼 글자가 이미지에 박혀 있는지 확인한다.
3. 카드·버튼의 가로세로 비율이 원본과 달라졌는지 확인한다.
4. 9슬라이스 모서리에 검은색 또는 불투명 사각형이 보이는지 확인한다.
5. 클릭 영역과 보이는 이미지 영역이 같은지 확인한다.
6. 빈 상태·선택 상태·비활성 상태에서 문구와 색상이 맞는지 확인한다.
7. 같은 기능의 뒤로가기·확인·삭제 버튼이 화면마다 다른 규격인지 확인한다.

## 공통 개선 원칙

- 글자가 박힌 완성형 이미지는 가능한 한 무문자 프레임과 HTML 텍스트로 분리한다.
- 크기가 변하는 패널과 버튼은 9슬라이스를 사용하고, 단순 `100% 100%` 확대는 시각 검증 후에만 허용한다.
- 임시 사각형 덮개로 원본 에셋을 가리지 않는다.
- 제목 리본·기본 버튼·보조 버튼·위험 버튼·슬롯 배지는 공통 무문자 세트로 관리한다.
- 해결된 문제도 삭제하지 않고 상태를 `해결`로 남겨 재발 여부를 확인한다.
