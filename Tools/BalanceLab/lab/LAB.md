# 밸런싱 랩 — 수치를 바꾸고 그 자리에서 다시 잰다

`lab/balance-lab.html` 을 연다.

- **더블클릭해도 열린다.** 그때는 브라우저가 파일 읽기를 막으므로 `data/balance.json` 을
  화면에 **끌어다 놓거나** 파일 고르기로 준다.
- 로컬 서버로 열면 알아서 불러온다.

## 고리

```
수치를 만진다  ->  다시 재기(300판 · 0.05초)  ->  밴드 안인가 본다  ->  마음에 들면 내려받는다
```

시뮬은 **그레이박스·`remeasure.js` 와 같은 코드**(`sim/v6-sim.js`)를 쓴다.
씨앗도 같은 자리(900000 부터 7 씩)라 **`remeasure.js` 와 같은 값이 나온다.** 확인했다.

## 만질 수 있는 것 28개

```
여정      시작 자금 · 일수
상회      승급비 3단계 · 보관칸
감정      비용 비율
경쟁자     숙적 초기 자본 · 성장률 · 입찰 상한
시세      평균회귀 phi · 하루 충격 sd
담보 대출   한도 · 상환 배수 · 만기 · 해금 단계
의뢰 보상   5종
족보 배수   6종
```

## 지키는 것

**바꾼 값은 내려받기 전까지 아무 데도 안 남는다.** 원본은 안 건드린다.

- 바꾼 자리는 **노란 테두리**로 표시되고, `바꾼 것` 상자에 원래 값과 함께 뜬다
- 아직 그 값으로 안 쟀으면 배너가 **"아직 이 값으로 안 쟀다"** 라고 말한다
- 잰 뒤에 또 만지면 결과에 **"지금 값과 다르다"** 가 붙는다
- 밴드(도달 45~60% · 마감실패 <38% · 생존중앙 ≤250,000)는 **랩이 못 넓힌다.** 사람이 승인한 기준이다

## 내려받은 다음 — **명령 하나**

`balance-lab.json` 이 떨어진다. 안에 `labEdit` 이 들어 있다 — 무엇을 바꿨고 얼마가 나왔는지.

**그것만으로는 확정이 아니다.** 덮어쓰고 한 줄 돌리면 된다.

```bash
cp balance-lab.json data/balance.json
python apply-balance.py
```

이 한 줄이 **뒤따라야 할 것을 전부 한다.**

```
1  다시 잰다            기준·대출 두 정책 · 씨앗 900 -> measuredAt · loan.measured · sets.measured
2  규칙을 다시 뽑는다      balance.json -> greybox/rules-v6.js
3  안내서를 맞춘다        PLAY.md 의 수치·대출 조건
4  검사한다             규칙=balance 대조 · 사람이 칠 수 있는가 · 기록 재현
                     밴드 판정 900판 · 기록->재현 고리 · 계약 검증 · 낡은 말
```

**판정은 exit code 다.** 하나라도 안 맞으면 1 로 죽고 무엇이 틀렸는지 찍는다.

```bash
python apply-balance.py --check    # 아무것도 안 바꾸고 검사만
```

### 이게 왜 필요한가

전에는 네 명령이 흩어져 있었다. **하나만 빼먹으면 조용히 갈라진다** —
규칙을 안 뽑으면 그레이박스가 옛 값으로 돌고, 안내서를 안 맞추면 사람이 틀린 기대를 갖고 앉는다.
둘 다 실제로 일어났다.

### 깨졌을 때 이렇게 나온다

```
밸런스를 깨면    FAIL · 안 넘어간 단계: greybox-test · 밴드 판정        exit 1
규칙만 손으로    ★ 그레이박스에 알려지지 않은 실패 1건이 더 있다
              FAIL  규칙 = balance · 대출 상환   9.9 / 1.9          exit 1
정상           PASS · 알려진 빨간불 2건만 남았다                      exit 0
```

`알려진 빨간불 2건` 은 그레이박스 자동 플레이 정책이 약해서 나는 것이다(사람 플레이와 무관).
**그 둘 말고 하나라도 더 있으면 안 넘어간다** — 가림막이 새 실패를 덮지 않는지 시험해 뒀다.

## 조심할 것

- **300판은 흔들린다.** 도달률이 ±3%p 쯤 움직인다. 결정을 굳힐 때는 900판으로 본다
- 랩은 **기준 정책**(대출도 의뢰 추격도 안 함)으로만 잰다.
  대출을 켠 정책은 `node sim/record-measurement.js` 가 같이 재 준다
- 한 번에 하나씩 만지는 게 낫다. 둘을 같이 바꾸면 **어느 쪽이 움직였는지 못 가른다**
