작업 순서

1. 그룹과 씬으로 전체 흐름을 배치합니다. 씬 선택은 카드를 클릭하고, 이동은 오른쪽 위 ⠿ 손잡이를 드래그합니다.
2. 씬을 연결하고 발동 조건을 작성합니다.
3. 씬을 더블클릭해 목업을 등록합니다.
4. 기능 사양 탭에서 핀·영역과 완료 조건을 작성합니다.
5. 팝업·연출 탭에서 부모 씬 전용 UI와 모든 씬에서 접근하는 전역 UI를 별도로 관리합니다.
6. 설정처럼 어느 화면에서나 여는 UI는 적용 범위를 전역으로 지정하고 한 번만 목업·배치합니다.
7. 배치 검사를 거친 뒤 씬별 폴더, 전역 UI 폴더, 공용 에셋 폴더가 분리된 프로젝트 ZIP을 저장합니다.
씬을 클릭하면 이전 씬과 다음 씬만 선명하게 남고, 연결 방향에 따라 선 색이 구분됩니다.

프로젝트 저장과 복원
프로젝트 ZIP이 기본 저장·복원 형식입니다. 각 씬은 scenes/<sceneId>/, 전역 UI는 global/ui-states/, 공용 재료는 shared/에 저장됩니다. JSON은 설계 데이터만 별도로 확인하거나 백업할 때 사용합니다.
