# VSL Clean UI 편집기

다운로드 폴더에서 사용하던 수정본을 저장소에 포함한 버전입니다.

## 실행

1. 저장소를 내려받거나 GitHub의 이 폴더를 다운로드합니다.
2. `VSL_레이아웃_9SLICE_실행.html`을 Chrome 또는 Edge로 엽니다.
3. `프로젝트 ZIP 열기`로 VSL 프로젝트를 불러옵니다.
4. `에셋 보관함 → Clean UI 프리셋`으로 버튼 5종과 저장 슬롯을 등록합니다.
5. 편집 후 `폴더형 프로젝트 ZIP`으로 저장합니다.

## 포함된 수정

- Clean UI 9-Slice 프리셋
- 편집 캔버스의 실제 9-Slice 미리보기
- 버튼/프레임 역할에 따른 요소 타입 자동 지정
- ZIP 재저장 시 `actionRef`, `dataRefs` 등 구현 메타데이터 보존

대용량 VSL 프로젝트 ZIP과 사운드 원본은 GitHub 일반 파일 제한 때문에 이 폴더에 포함하지 않습니다.
