# 디자인 자료 안내

이 폴더는 게임에 직접 배포하지 않는 화면 설계와 VSL 편집 원본을 보관한다.

- `Mockups/미지의경매장-2026-07-24/` — 2026-07-24 화면 목업 프로젝트
  - `assets/` — 편집용 원본 이미지
  - `mockups/` — 화면별 번호가 붙은 검토 이미지
  - `flow.json`, `layout.json` — 당시 화면 흐름과 배치 정의
- `VSL-v6.4-audio-v3.6/` — V6.4 VSL·사운드 통합 프로젝트
  - 씬, 레이아웃, 계약, 사운드 원본과 검증 도구를 포함한다

실제 게임 본체는 `../Runtime/`, 제작용 이미지 원본은 `../Assets/`에 있다.
VSL 폴더는 내부 상대경로를 사용하므로 하위 파일을 개별적으로 분리하지 않는다.
