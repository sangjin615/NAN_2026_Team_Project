# 서버 없이 실행하기

1. 저장소를 ZIP으로 받았다면 먼저 전체 압축을 풉니다.
2. `Runtime/미지의_경매장_서버없이_실행.html`을 Chrome 또는 Edge로 엽니다.
3. 별도의 터미널, Node.js, 로컬 서버 실행은 필요하지 않습니다.

실행 HTML에는 게임 코드와 필수 JSON 데이터가 내장되어 있습니다. 이미지와 사운드는 같은 `Runtime` 폴더의 `assets` 및 `sound` 폴더를 사용하므로 실행 HTML만 따로 옮기면 안 됩니다.

개발 중 내용이 변경되면 다음 명령으로 실행 HTML을 갱신합니다.

```powershell
npm.cmd install
npm.cmd run build:standalone
```

브라우저가 로컬 파일 실행을 차단하는 특수한 보안 설정을 사용하는 경우에는 기존 개발 방식인 `npm.cmd start`를 사용합니다.
